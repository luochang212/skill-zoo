## Why
Discover currently requires knowing a repository or a search term. Add community recommendations while retaining a calm interface and the existing GitHub installation flow.

## What Changes
- Add popular and 24-hour trending GitHub skills from skills.sh through Rust IPC.
- Preserve last successful catalogs for network failures; isolate curated repositories from feed failures.
- Show concise cards, diverse repository exposure, and progressive expansion.
- Resolve catalog slugs against actual repository skills before preview or installation.

## Capabilities
### New Capabilities
None.
### Modified Capabilities
- `discover-search`: community discovery and targeted preview.

## Impact
Rust discovery command, typed API/query hook, Discover layout, repository preview, mirrored translations and tests. No install protocol changes or new dependencies.
