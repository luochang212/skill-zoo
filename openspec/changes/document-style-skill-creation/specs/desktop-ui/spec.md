## ADDED Requirements

### Requirement: 文档式技能创建

本地页「我的」的创建技能页 MUST 在同一连续书写区依次提供名称、描述与正文，以标题字号及次级文字区分层级，并用统一行宽、页边距和页首/正文间细分隔线建立文档边界，沿用应用页面背景，不添加悬浮卡片外框或阴影，不显示多余的「正文」标签，MUST NOT 为三个字段绘制独立框线。描述和正文 MUST 随内容增高并随整页滚动；返回及显式创建 MUST 位于同一文档纸面顶部，与编辑区统一背景、宽度和滚动，不设独立操作栏分隔线；创建页不提供查看/编辑/分屏切换。字段 MUST 具有可访问名称。正文使用 Markdown，名称校验和创建 IPC 保持不变，多行及含特殊字符的描述 MUST 序列化为有效 frontmatter。

#### Scenario: 连续书写并创建
- **WHEN** 用户填写有效技能名、多行描述与正文并点击创建
- **THEN** 同一页完成书写，通过现有创建流程生成可解析的 frontmatter 与原样正文，成功后进入已创建技能

#### Scenario: 非法名称不提交
- **WHEN** 名称为空或不符合现有命名规则
- **THEN** 创建按钮不可用，非空非法名称显示规则提示，描述及正文草稿保留

### Requirement: 本地页同构管理入口

本地页「导入」分类 MUST 在与「我的」分类创建技能按钮相同的位置常驻「导入管理」按钮，两者 MUST 使用相同的主按钮尺寸、圆角、配色及间距。入口 MUST 复用设置页的导入管理弹窗，不引入独立管理流程；没有导入技能或筛选结果为空时也 MUST 保留入口。

#### Scenario: 空导入列表仍可管理
- **WHEN** 用户进入导入分类且当前无导入技能
- **THEN** 列表上方保留同构主按钮，点击打开现有导入管理弹窗，关闭返回原分类和筛选状态
