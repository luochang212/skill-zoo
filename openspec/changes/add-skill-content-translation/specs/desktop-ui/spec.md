# Spec Delta

## MODIFIED Requirements

### Requirement: 表单控件的焦点可见性

共享输入控件 MUST 在键盘聚焦时提供可感知的焦点指示。实现 MUST NOT 仅移除默认轮廓而不提供替代指示。文本输入激活态 MUST 使用极淡的单像素边框变化，不绘制强对比边框或光圈。输入控件 MUST 沿用"边框颜色变化"这一既有视觉语言，不得改为绘制描边环。

#### Scenario: 键盘聚焦输入框可见
- **WHEN** 用户用 Tab 聚焦到共享输入框或列表搜索框
- **THEN** 保留轻量的边框提示与正常键盘焦点行为

#### Scenario: 焦点指示沿用边框语言
- **WHEN** 输入控件获得键盘焦点
- **THEN** 指示以边框颜色变化呈现，不绘制额外的描边环
