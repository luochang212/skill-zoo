# agent-visibility

## Purpose

定义隐藏/显示 Coding Agent 的行为契约：可见性偏好的持久化与技能链接清理的关系、清理的所有权边界、以及清理失败时的降级行为。

## ADDED Requirements

### Requirement: 隐藏偏好必须成功

用户隐藏一个 Coding Agent 的偏好 MUST 被保存并生效，无论该 agent 技能目录中的链接清理是否成功。仅当设置持久化自身失败时，操作才 MAY 失败并报错。

#### Scenario: 链接清理失败不阻断隐藏

- **WHEN** 用户隐藏某个 agent，且该 agent 技能目录中的链接因环境原因（权限、跨卷等）无法移出
- **THEN** 隐藏偏好照常保存并生效，界面反映该 agent 已隐藏，并展示一条简洁的状态提示说明部分技能链接未能清理

#### Scenario: 设置持久化失败仍报错

- **WHEN** 用户隐藏某个 agent，且设置文件写入失败
- **THEN** 操作失败并报错，可见性偏好与技能目录均保持操作前状态

### Requirement: 清理只触碰应用拥有的链接

隐藏 agent 时的链接清理 MUST 只移除由本应用创建的技能链接——即目标指向 SSOT 存储或应用已登记技能主目录的符号链接。其它符号链接（含目标无法判定的链接）MUST 保留原位，不被移动或删除。

#### Scenario: 外来链接保留

- **WHEN** 被隐藏 agent 的技能目录中存在不由本应用创建的符号链接（如该 agent 自身管理的技能链接）
- **THEN** 这些链接原样保留，隐藏操作继续进行

#### Scenario: 应用链接被清理

- **WHEN** 被隐藏 agent 的技能目录中存在指向 SSOT 存储的技能链接
- **THEN** 这些链接在隐藏成功后被移除，SSOT 存储中的技能实体不受影响

### Requirement: 清理失败降级为简洁状态提示

链接清理失败时，界面 MUST 仅以单句状态提示告知"已隐藏但部分链接未清理"，MUST NOT 展示原始错误码或文件路径；失败详情 MUST 写入标准错误流供诊断。

#### Scenario: 提示简洁且可诊断

- **WHEN** 隐藏时链接清理失败
- **THEN** 界面提示不包含错误码与路径；从终端启动应用时，标准错误流中可见失败原因与涉及路径

### Requirement: 无主动重试

清理失败后应用 MUST NOT 自动重新尝试清理。用户将该 agent 再次隐藏（先取消隐藏再隐藏）MUST 触发新一轮链接清理，且该清理对已不存在或指向一致的链接幂等。

#### Scenario: 重试由用户触发

- **WHEN** 隐藏后仍有应用链接残留，用户将该 agent 取消隐藏后再次隐藏
- **THEN** 链接清理再次执行并处理残留链接；期间不发生任何自动后台清理

### Requirement: 可见性边界

可见 agent 数量 MUST 至少为 1 且至多为 7。试图隐藏最后一个可见 agent 的操作 MUST 被拒绝并提示原因。

#### Scenario: 最后一个可见 agent 不可隐藏

- **WHEN** 当前仅剩一个可见 agent，用户尝试隐藏它
- **THEN** 操作被拒绝并提示至少保留一个可见 agent
