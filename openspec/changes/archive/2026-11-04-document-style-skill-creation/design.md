# Design

使用有可访问名称的原生 input/textarea，去掉边框与背景，以字号、颜色、留白区分标题、描述与正文。居中限制行宽，沿用应用页面背景，不增加悬浮卡片的外框、阴影或背景色差；用统一行宽、页边距及页首下方细分隔线表达文档边界，正文直接接续书写，不额外显示「正文」标签。字段自身不绘制边框，正文保持 Markdown 文本编辑；不引入富文本编辑器或 contenteditable。返回和创建操作位于同一纸面顶部，与书写区使用相同背景和宽度，不设独立背景或横贯页面的分隔线，随页面统一滚动。

文本域按 scrollHeight 自适应高度，并在容器宽度变化时重新计算；整页仅一个滚动容器。使用已有 js-yaml 序列化 frontmatter，避免多行描述、冒号和引号破坏格式。技能名规则、空描述的既有默认值及显式创建流程保持不变。

用户随后允许联网和测试。布局参考公开文档及本应用详情页，使用开发版界面核对空白和多行输入状态；保存规则通过隔离测试验证，不在用户目录创建验证技能。实际检查结果见 verification.md。

本地导入列表复用设置页的管理弹窗，与「我的」分类共用同一主操作行和按钮样式；无结果提示在列表区顶部保留约 96px 间距、水平居中，不按剩余高度垂直居中。
