# Proposal

## Why

使用习惯持久化了 agent 选择，托盘最近使用却写死 Claude Code，且部分采集器把读取失败当空记录。用户确认统一选择、共享扫描缓存并明确加载/成功/空/失败状态。

## What Changes

- 共用已有 skill_usage_agent 设置，保存成功后两处切换；失败回滚，不展示其他 agent 的结果。
- Rust 持有按 agent 隔离的 30 秒缓存与扫描锁，页面和托盘共享扫描；保留同 agent 的旧成功结果及单独错误状态。
- 托盘标明来源，初次读取、空记录和错误使用不同呈现；支持错误重试、鼠标事件刷新与后台周期兜底。
- 区分缺失存储与读取失败，保留坏行及损坏压缩文件的既有容错。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `skill-usage`: 共享使用来源、扫描缓存和读取状态；托盘最近使用展示。

## Impact

修改使用采集器、应用内缓存、设置保存、托盘与使用习惯 UI。沿用既有设置键与统计结果；IPC 增加结果/错误快照，保证首次打开也可取得后台旧结果。无磁盘 schema、CLI 协议或用户文件迁移。
