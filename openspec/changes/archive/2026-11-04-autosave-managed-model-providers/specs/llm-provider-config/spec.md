## MODIFIED Requirements

### Requirement: 首次选择服务与后续列表管理
模型管理 MUST 区分首次模板选择与已有服务管理：无服务直接展示模板，有服务采用导航与详情分栏，窄窗口上下排列。详情 MUST 分离连接信息与模型列表，参数使用独立弹窗。新增服务只在显式保存后持久化；已有服务按自动保存规则持久化，切换或关闭前 MUST 等待在途保存，仍有未保存修改时确认放弃，MUST NOT 自动改绑翻译模型或启动翻译。

#### Scenario: 模型管理的连接与草稿布局
- **WHEN** 用户打开已有服务的管理页
- **THEN** 导航突出名称与启用模型数，添加入口固定于导航底部，详情不提供底部取消/保存按钮，显示轻量保存状态；名称在标题处编辑，服务开关在标题右侧三个点左边，首次配置页保持原位置
- **AND** 模型列表支持添加/移除，模型行提供独立编辑按钮；新模型默认可用，已有禁用模型保留状态且标记禁用，不提供模型开关
- **AND** 新增服务的保存按钮文案为「保存」，选择模板后取消返回模板页而不保存

#### Scenario: 密钥普通编辑与显式保存
- **WHEN** 用户编辑已有服务的密钥
- **THEN** 专用 IPC 读取真实值并以密码框默认隐藏，眼睛切换显隐，长度跟随真实值，不使用固定假掩码；新建直接输入
- **AND** 输入过程中及全选删除时只修改草稿，失焦后自动保存才生效；输入框内仅提供显隐按钮，不提供清除图标；未改动保留原密钥
- **AND** 读取期间或读取失败不得编辑密钥或提交，避免误保存为空


#### Scenario: 首次连接 Anthropic
- **WHEN** 用户无服务并在模型设置选择 Anthropic
- **THEN** 同一弹窗展示其预填表单，取消返回服务选择且不产生保存或模型调用

#### Scenario: 已有服务继续添加
- **WHEN** 用户已有服务并点击导航底部的添加服务
- **THEN** 进入模板选择页，保存后回到服务管理分栏，原翻译偏好保持不变

#### Scenario: 切换管理对象保留用户选择权
- **WHEN** 用户修改连接信息后切换另一服务商或添加服务
- **THEN** 先完成当前输入的保存并等待在途请求；成功后直接导航，失败或校验未通过则确认放弃，继续编辑保留当前草稿，翻译偏好均不改变

### Requirement: 凭据通过专用接口查看
普通供应商列表 MUST 只返回 Key 是否存在；编辑页 MUST 通过专用 Rust IPC 读取实际 Key，默认隐藏并允许用户显式显示。Key MUST NOT 出现在日志/错误中。编辑凭据 MUST 区分未变、替换、清除；清空草稿并保存 MUST 清除原 Key，空 Key 允许用于无认证本地服务。打开表单、查看 Key 或输入过程中 MUST NOT 自动保存或发起连接测试；已有服务的密钥编辑完成后按自动保存规则持久化。实际认证失败由调用报告，MUST NOT 在保存时验证联网。

#### Scenario: 修改名称
- **WHEN** 用户只修改名称而不替换凭据
- **THEN** 原 Key 保持不变，普通列表及保存摘要没有任何 secret 值

### Requirement: 模型参数编辑
模型行 MUST 提供编辑图标，添加/编辑模型使用同一参数弹窗，支持模型 ID、可选上下文窗口与最大输出 token。取消不修改草稿；确认更新当前服务草稿，已有服务随即自动保存，新增服务仍由保存按钮持久化；模型 ID MUST 非空且同服务唯一，数值 MUST 为正整数，均设置时输出上限 MUST NOT 超过上下文窗口。上下文窗口作为元数据保存，不声称可精确计算 token；最大输出继续用于模型请求。

#### Scenario: 编辑事务取消
- **WHEN** 用户编辑参数或接收自动回填后取消
- **THEN** 服务草稿、已保存配置与翻译偏好不变

### Requirement: 设置内容自适应布局
模型设置弹窗 MUST 按当前内容决定高度，仅限制最大高度，长内容滚动，新增服务的取消/保存固定可见，已有服务的保存状态保持可见。服务商导航 MUST NOT 因列表较长将短表单撑高，短内容末尾与底栏之间只留标准内边距。宽度允许并排时，接口类型与服务地址 MUST 按 2:3 分配可用宽度，窄窗口上下排列。模型标题旁的添加按钮与列表 MUST 位于模型区及弹窗边界内，空列表与窄窗口均不得横向越界。

#### Scenario: 无预设模型的短表单
- **WHEN** 用户选择任一推荐服务商或自定义服务，尚未添加模型
- **THEN** 模型列表为空，弹窗随内容收高，模型区域末尾直接衔接底栏，不保留固定高度造成的大块空白

### Requirement: 测试隔离与凭据保护
测试调用本身 MUST 不保存连接、不改变偏好或翻译缓存、不发送技能内容。未替换的密钥 MUST 只在后端读取；替换或清除使用当前草稿。反馈 MUST 不含密钥、上游响应体或原始网络错误。测试期间 MUST 防止重复提交，配置改变、切换服务或关闭后旧结果 MUST NOT 产生误导性成功反馈。未主动测试时 MUST NOT 发起推理请求。

#### Scenario: 未保存的连接修改
- **WHEN** 用户修改地址或密钥后测试某个模型
- **THEN** 使用草稿测试，测试调用本身不写配置、不改变偏好及缓存；已有服务因输入失焦触发的自动保存独立处理

#### Scenario: 测试中改变草稿
- **WHEN** 测试尚未返回时修改配置或离开当前服务
- **THEN** 旧结果不显示为当前配置的成功或失败

## ADDED Requirements

### Requirement: 已有服务自动保存
已有服务的名称确认、地址与密钥有效失焦 MUST 自动保存；协议、启用状态和模型增删改确认 MUST 立即保存。输入中间态 MUST NOT 写入；无效或失败时 MUST 保留草稿和安全错误，支持显式重试。写入 MUST 按编辑顺序串行，旧响应 MUST NOT 覆盖新输入。界面 MUST 区分保存中、已保存、未保存和保存失败，不自动切换翻译偏好或调用模型。首次添加服务与模型参数弹窗 MUST 保留显式确认。

#### Scenario: 连续编辑期间保存返回
- **WHEN** 一次保存尚未返回时用户完成下一次编辑
- **THEN** 下一次写入等待前次结束，表单保留最新输入，只有最新草稿保存成功才显示已保存

#### Scenario: 保存失败与离页
- **WHEN** 自动保存失败或地址无效，用户切换服务、返回或关闭管理页
- **THEN** 原输入保持可编辑且错误可识别；离页需确认放弃，继续编辑可重试，已保存配置保持最后成功值
