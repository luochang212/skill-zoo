# Design

## Context

现有 SkillContentPane 同时显示 SKILL.md 与辅助文件；RepoDetail 是独立 Markdown 远程预览，不复用此面板。本 change 只扩展本地技能详情。网络、文件读取与缓存仍由 Rust Tauri 命令所有；新建页没有持久技能身份，不显示翻译。设置已有独立 SettingsView 与安全 atomic_write_private。见 proposal 与 worth-fix 报告，不沿用缺失出处的竞品结论。

## Goals / Non-Goals

交付三协议、多供应商、当前文件手动流式翻译、持久语言/模型偏好与受保护缓存。前端零新增依赖。无自动翻译、右键入口、批量、分块、远程预览、双语对照新模式、拖拽排序、推理档位、OAuth 或泛化配置框架。现有分屏仍为编辑器/原文预览。

## Decisions

### D1. 显式协议与共用连接层

使用 genai 0.7 系列最新稳定补丁，禁用默认特性，启用 rustls-tls；复用现有 reqwest client。协议映射到 AdapterKind，直接使用明确 ModelIden/ModelSpec，禁止环境 Key 或模型名路由替代用户配置。Base URL 规范化目录尾斜杠，三协议 wire 验证实际地址、头、流与终止原因。头超时 30 秒、流空闲 30 秒、总时限 180 秒，输出限制 256 KiB。不自动重试生成。

### D2. 配置与偏好分离

供应商位于 get_app_config_dir()/llm_providers.json，schemaVersion=1，持久可选 Key、模型 id/enabled/maxOutputTokens。前端 summary 只含 hasApiKey，更新以 Option 区分未变与替换（空值清除）。认证和协议请求头由连接层生成，不提供高级选项或自定义头。旧配置中的 headers 字段由 serde 忽略，不再参与发送或后续保存。保存经 mutex 串行、atomic_write_private，避免半写和运行态提前生效。损坏只读报错，显式恢复先备份；未来版本拒绝恢复/写入。无虚构旧版本迁移。Windows 继承现有用户应用目录 ACL。

翻译偏好独立文件 translation_preferences.json（语言、providerId、modelId），不进入 CLI 的 settings/技能协议。前端 React Query 管理后端偏好；首次从原始 navigator.languages 匹配 zh-Hant/TW/HK/MO 与 zh-Hans/CN，再匹配其他支持语言，之后界面语言、英语；不通过修改全局 i18n 初始化。只有用户交互才持久保存。模型必须显式选择，无静默回退。设置主页面的高级功能整组位于 Coding Agent 设置之后、关于之前；组内只保留与既有设置一致的图标、标题/摘要、outline 操作按钮卡片（模型管理使用 ListTree + 管理，翻译使用 Settings2 + 设置）；「模型设置」与「翻译选项」有独立入口。AiSettingsDialog 作为共用遮罩详情容器，内部切换翻译、供应商管理分栏、模板选择与新建表单；翻译页删除文档发送提示。可用模型为空时，以与下拉栏同尺寸的「去配置」主按钮替代模型下拉；容器在同一弹窗切到模型管理，并提供返回翻译设置入口。已有可用模型时保留下拉；加载和读取失败不作为空配置。连接也可通过独立入口管理，且无翻译前置条件。翻译页只读取供应商摘要和 ID 引用，不拥有连接/凭据，也不导入供应商表单；导航由弹窗容器编排。供应商保存刷新公共查询，返回后由用户显式选择新模型，语言与原模型偏好保持，绝不自动生成。下拉统一使用与使用习惯相同的 Radix DropdownMenu、ChevronDown 与 Check，避开 Safari 16.4 无法自定义的原生 picker。表单标签与控件间距 8px，字段组间距 20px，36px 控件高度与 12px 正文字号，弹窗内边距沿用 16px；启用状态沿用共享 Switch 滑块开关。说明文字表达用户操作（选择阅读语言与模型），不罗列实现保证。弹窗沿用已有 Dialog/ScrollArea、固定标题与可滚动内容、Esc/遮罩/关闭按钮及返回焦点；关闭后保留技能页面与草稿。

### D3. 内容快照与任务取消

前端发送 skillId、相对文件 path、显示的 source 快照、目标与预先生成 taskId；后端复用技能文件安全读取，比较磁盘内容与 source，拒绝不一致，不信任任意路径。归档走既有只读解析。前端 dirty/savePending 阻止触发。

注册采用前端先发 start_translation_task(taskId) 获确认，再 translate 请求；start 登记 futures AbortHandle/AbortRegistration，cancel 显式 abort，取消发生在 translate 之前也保留 aborted registration。translate 取出 registration、保留 handle 到终态，Abortable 包裹网络 future。任务完成/取消共享注册表锁，完成提交点先于取消则缓存可提交，取消先到则不能提交；清缓存有 epoch 防止在途回填。离页清理也覆盖启动确认尚未返回的情况。所有事件附 taskId，前端会话代次隔离。Channel 仅传输，不当作取消保障。

### D4. 保真与缓存

Markdown 预处理用占位符保护围栏、行内代码、链接目标与 frontmatter 中非 description 内容；frontmatter description 单独作为待译文本并在恢复时安全序列化 YAML。响应须每个占位符恰出现一次；不一致拒绝缓存。代码与链接从源文恢复，不依赖模型“听话”。自然语言路径/命令与结构属于 prompt 质量目标，避免承诺确定性语义安全。占位符后缀由源文 64 位哈希缩短为 6 位十六进制，源文包含共享前缀时按确定性递推避让；模型需逐字复现的标记大幅变短，长文档保真成功率显著上升，标记格式与校验语义不变，策略版本随之升为 2。保真失败后执行至多一次定向修复：以未受损标记为锚点定位损坏区间，仅把含损坏标记的源文片段按编号协议重新送译，解析后在锚点间确定性拼接，最终仍须整体通过保真校验方可入库；发起前前端必须弹出可见提示 Toast，不静默重试。整篇原样重发（重掷全部标记、注意力稀释）与模型自报 diff（锚点转述易失配）均不采用。

缓存 hash 规范化序列化协议/URL/model/maxOutputTokens/语言/source/策略版本；不含 API Key 和对象身份。StreamEnd.captured_stop_reason 只接受 Completed，其他原因及未知拒绝成功；通过保真校验后原子保存。强制重译只绕过读，不预删。内容缓存与原文查询分开，不写文件。相同配置允许共享缓存。clear 递增 epoch，在途任务不回填。

### D5. 工具栏与状态

查看/编辑/分屏右侧细分隔线 + Languages 翻译 ChevronDown，h-6、text-[11px]、rounded-lg、中性背景，使用现有 Radix dropdown 的键盘/焦点管理（Safari 16.4）。编辑/分屏保留禁用位置；Markdown 只读来源可用，其他文件/新建页隐藏。一个菜单含翻译目标、语言、原文/译文、重译/取消、设置；无右键/自动翻译。译文选中态与 tooltip，无常驻 badge。切到编辑显示原文、流可继续，改动原文则取消；文件/语言/模型变化重置任务与译文。重译保留旧成功文本，失败恢复旧文本；只有初次翻译显示增量。重新打开默认原文。

### D6. 模型设置的首次配置与列表管理

首次无服务时直接显示五个服务商与自定义组成的六张网格卡片，卡片以中性首字标记、名称和域名提供识别信息，选择后在同一遮罩中只预填连接信息，所有模板的模型列表为空，由用户自行添加。已有服务采用左侧 180px 导航与右侧详情，弹窗最大宽度 684px；窄窗口上下排列。各页按内容收高，服务商导航在宽屏不参与内容高度计算，避免长列表撑出短表单空白；正文超高滚动，底栏固定。导航只改变管理对象，不改变翻译偏好；添加固定于导航底部，详情取消/保存固定于右侧底部。修改后切换服务商或添加先确认放弃，继续编辑保留草稿，取消恢复已保存值。连接区突出地址、协议与 Key，宽屏接口类型与地址按 2:3 分配，窄区域堆叠；新建及编辑均使用真实 Key 的密码输入框并支持显隐和清空草稿；已有 Key 通过专用 IPC 读取，供应商列表仅返回存在状态。模型以紧凑列表管理，新增由列表标题旁的添加按钮打开空参数弹窗；不提供高级选项或自定义请求头；模型参数放在独立编辑弹窗。保留显式保存，不继承参考项目的即时保存、默认模型联动、localStorage 凭据或浏览器直连。连接测试/模型拉取不在本轮 UI 范围内。

服务商选择页按内容自适应高度，只限制最大高度，小窗口可滚动；五张预置服务商卡片统一淡青绿色，第六张为淡蓝色自定义卡片，删除 Ollama 预置与底部自定义横条，下方保留标准内边距。返回使用标题左侧 16px 箭头、32px 点击区，描述与标题左对齐；叉叉始终关闭弹窗。

### D7. 模型编辑与公开参数目录

借鉴 ZCode 的独立模型编辑、推荐基线与手动覆盖优先，不依赖其私有规则源。采用 Models.dev 公开匿名 https://models.dev/api.json，Rust 请求固定地址，10 秒时限、16 MiB 上限、成功 24 小时内存缓存、失败 30 秒合并重试，按服务 URL 与模型 ID 精确匹配；未知代理/自定义模型不猜测。模型编辑器防抖 400ms，生命周期与目标身份隔离迟到回包，手动字段优先；已保存数值默认保留，不提供推荐操作按钮或提示区，自动匹配成功复用 Sonner toast，未命中/失败静默且不阻塞手填。模型确认仅更新服务草稿，外层保存才落盘。上下文是可选元数据；最大输出参与实际请求，二者均为正整数且输出不大于上下文。已有配置缺少上下文字段仍可读写，无迁移或 CLI 协议变更。

## Risks / Trade-offs

- genai 0.x 变更风险 → Cargo.lock 固定，三协议 mock 集成覆盖，不引 agent 框架或手写 SSE。
- 模型质量不确定 → 保护可识别语法，校验失败显式处理；不承诺所有命令语义安全。
- 51,200 字节限制 → 清晰提示；本机样本不能代表社区，不据此断言无长文需求。
- Key 明文 → 后端所有、私有原子写、错误不透传供应商响应；不强制引 Keychain。
- 缓存落盘失败 → 返回可识别失败，不覆盖旧缓存；不改技能原文。

## Migration Plan

新增两个独立配置文件与 translations 缓存，不改变现有本地协议、CLI 或 fixtures。无存量迁移；回滚可保留派生缓存。保留 ADR 1/5 的边界。选型理由由 change 归档持有，不为依赖变更新建重复 ADR。
