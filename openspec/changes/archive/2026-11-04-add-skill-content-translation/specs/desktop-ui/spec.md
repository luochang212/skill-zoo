## MODIFIED Requirements

### Requirement: 表单控件的焦点可见性

文本输入框、多行文本框及设置下拉栏 MUST 保持正常键盘聚焦与操作，但 MUST NOT 因聚焦或展开而改变边框颜色或绘制额外光圈。控件 MUST 保留静态边框、插入光标、可访问名称、禁用及错误状态。其他按钮等控件的焦点样式不在本项调整范围。

#### Scenario: 输入框保持静态边框
- **WHEN** 用户点击或用 Tab 聚焦共享输入框、列表搜索框或多行输入框
- **THEN** 可正常编辑，边框不提亮且不绘制外圈

#### Scenario: 设置下拉栏展开
- **WHEN** 用户聚焦或打开设置下拉栏
- **THEN** 菜单和键盘操作正常，触发器边框不提亮
