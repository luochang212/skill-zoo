## MODIFIED Requirements

### Requirement: 后台更新退出确认

真实退出入口在批量或所选更新命令存活时 MUST 要求确认，取消 MUST 保留窗口与任务，重复退出请求 MUST NOT 堆叠确认。窗口关闭与托盘退出 MUST 覆盖；macOS 系统 Cmd+Q 与 Dock 退出受当前原生框架限制，不保证确认。没有后台更新时 MUST 保留既有退出行为。

关闭到托盘设置（`close_to_tray` 为 `"true"`）MUST 默认关闭。启用时，关闭主窗口 MUST 是隐藏而非退出：MUST NOT 结束进程，MUST NOT 出现退出确认，进行中的更新继续。隐藏后用户 MUST 能从托盘「打开主界面」与 macOS Dock 图标恢复窗口并获得焦点。启用后，真实退出（托盘「退出」、Cmd+Q）MUST 仍然经过退出确认。关闭该设置时，关闭主窗口 MUST 回到既有退出行为。

#### Scenario: 更新中关闭窗口或托盘退出
- **WHEN** 未启用关闭到托盘且后台更新存活，用户关闭主窗口或选择托盘退出
- **THEN** 显示本地化退出确认，取消后窗口与更新仍存活，确认后退出

#### Scenario: 未更新或任务结束
- **WHEN** 没有后台批量更新，用户请求退出
- **THEN** 无更新确认，按既有行为退出

#### Scenario: 启用关闭到托盘后关闭窗口
- **WHEN** 启用关闭到托盘且后台更新存活，用户关闭主窗口
- **THEN** 窗口隐藏，进程与更新继续，不出现退出确认

#### Scenario: 从托盘或 Dock 恢复隐藏的窗口
- **WHEN** 窗口已隐藏，用户点击托盘「打开主界面」或 macOS Dock 图标
- **THEN** 主窗口显示并获得焦点
