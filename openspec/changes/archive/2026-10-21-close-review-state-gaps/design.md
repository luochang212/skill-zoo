# Design

## Context

现有共享租约互斥己方写者，metadata RwLock 保护内存；刷新不取租约。编辑器在 App 内跨详情会话存活，辅助编辑组件可能在同 directory 的不同 skillId 间复用。

## Goals / Non-Goals

目标是修复六项已报告边界并固化反例。不新增事务框架、草稿全局存储或协议版本，不改变合并主动迁移语义。

## Decisions

1. 刷新在持 metadata 写锁后读盘并替换。批量删除收集成功 ID，再持一次元数据锁删除并保存，消除未落盘变更被刷新插入的窗口；保持既有缓存→元数据锁顺序。
2. SKILL.md 保存捕获单调编辑会话代次。打开/确认切换/关闭会话时推进代次，迟到保存回调不影响后来会话，即使 skillId 或文本相同。
3. 辅助编辑器在 skillId/directory 改变时重置，保存与懒加载回调校验会话代次。正文回到已存基线则删除草稿；同文件保存中暂留撤销意图，成功时用提交正文更新查询缓存，避免旧基线导致误清。
4. 合并复制遇任何链接直接拒绝，且仅清理本次创建的目标；不追随目录链接，也不删除原件或外部目标。
5. 安装锁更新继承同 ID 旧条目的 extra，已有 fixture 检验真实更新函数而非只检验 serde 往返。

## Risks / Trade-offs

读盘在 metadata 写锁内稍延长临界区，代价换取一致性。含链接技能须手工合并，沿用原有文件链接拒绝策略。并发测试复用真实刷新函数、临时家目录和可控锁阻塞；无真实用户目录操作。
