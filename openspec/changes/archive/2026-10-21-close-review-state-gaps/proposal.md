# Proposal

## Why

2d75a27 的修复验收发现：刷新先读盘后取锁、保存未绑定会话、同目录不同技能串草稿、撤销后 dirty 不一致、合并忽略目录链接、重装清空 lock 附加字段。前五项影响用户状态或技能可用性；最后一项为既有 ADR 的低成本保留约定。均可在现有结构中局部补齐。

## What Changes

- 元数据重载先取写锁，批量删除在一次元数据锁内变更并持久化。
- 保存完成只确认原编辑会话；辅助草稿随技能身份重置，撤销回已存正文时清理草稿。
- 合并拒绝会丢失符号链接的源，出错时清理本次创建的目标；原件和外部链接目标保持不变。
- 更新已有 lock 条目时保留未知可选字段；修正保存测试的初始化假阳性。

## Capabilities

### Modified Capabilities

- `desktop-ui`: 编辑会话隔离、辅助草稿还原与在途保存的边界。
- `local-protocol`: 刷新/写入交错、合并链接保护及重装附加字段保留。

## Impact

触及 Rust skill/cli 服务、删除命令，前端 editor/pane 和文件保存 hook，以及现有测试与协议说明。不改协议版本、不新增依赖、不扩展外部管理器兼容。

## Verification Boundary

使用临时家目录、真实生产函数与模拟 IPC 的 React 测试。目录链接测试用 Unix symlink；Windows junction 由同一现有识别函数保护但本机未实测。未知字段通过既有共同 fixture 直接调用安装锁更新函数核验，无需真实网络安装。
