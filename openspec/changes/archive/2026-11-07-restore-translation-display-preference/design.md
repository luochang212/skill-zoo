## Context
单独恢复设置开关和缓存条件不够：已手动翻译的会话保存在 QueryClient 中，返回后仍会带着 showTranslation=true。用户明确要求关闭时每次进入先显示原文，开启时沿用当前译文优先与选择记忆。

## Decision
保留共享会话和后台任务作为结果来源；新增组件实例内的主动选择标记，按文档身份及偏好隔离。关闭时新进入的视图不自动显示共享译文，当前页面手动翻译或切换才显示；导航或偏好改变重置这个标记。开启时直接使用共享会话选择，并按既有资格读取磁盘缓存。视图默认原文不改写共享结果或中止后台任务。

使用原有 Switch、偏好保存 API 和 Rust serde(default) 字段。缺字段按关闭。现有强制重译传参及逐步预览、失败/取消回退保持有效。不持久化每份文档的界面选择，不增加迁移或依赖。

## Risks
关闭时返回正在翻译的文件先显示原文，但任务与进度仍继续；已有结果可手动查看。开启后的会话选择仍可能保留原文，这是尊重用户明确切换的既有行为。当前未提交的进度条配色和重译修复保留。

## Validation
先验证默认关闭、保留会话重进和 A→B→A 导航：三项测试在旧实现失败。覆盖开启后的重启缓存恢复、原文选择记忆、关闭时后台完成不自动切换、手动查看复用结果，以及关闭后迟到缓存不生效。设置测试验证默认关闭及保存字段，Rust 测试验证缺字段默认和序列化往返。
