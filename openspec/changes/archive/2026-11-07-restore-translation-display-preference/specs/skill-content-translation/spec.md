## MODIFIED Requirements

### Requirement: 状态与只读展示
下拉 MUST 提供翻译为当前目标语言、语言选择、翻译设置；有结果时提供原文/译文切换与重译，翻译按钮右侧在翻译及自动修复中显示中止按钮，终止失败后显示重试按钮，其余状态不显示；中止从下拉移至该按钮，按钮只显示图标，悬停提示和可访问名称保留动作文字。初次翻译等待首段正文时 MUST 保留可阅读原文，MUST NOT 用加载图标或空状态替换正文；收到正文后流式显示，允许查看原文；重译等待首段新正文时保留旧成功译文，收到非空预览后 MUST 渐进显示新译文；重译失败或取消 MUST 恢复旧成功译文，只有成功后才替换成功结果与磁盘缓存；用户在生成期间切回原文后，完成 MUST NOT 强制切回译文。译文通过按钮选中态与 tooltip 标识，无常驻模型/AI 文字。编辑或分屏 MUST 使用原文，任何译文 MUST NOT 进入原文草稿或保存路径。当前会话的任务与结果 MUST 保留；重新进入时的正文展示 MUST 遵循「优先显示译文」偏好。自动读取 MUST NOT 发起模型请求。

#### Scenario: 从译文进入编辑
- **WHEN** 用户在译文视图切到编辑
- **THEN** 编辑器仅显示原文，已有草稿保护继续生效

### Requirement: 优先显示缓存译文
翻译设置 MUST 提供持久化的「优先显示译文」开关，默认关闭，缺字段按关闭读取。关闭时每次进入 MUST 先显示原文，即使共享会话已有译文或后台任务；当前页面手动操作可显示已有结果，不丢弃缓存或中断任务。开启时 MUST 恢复会话选择；无匹配会话时自动读取有效磁盘缓存，命中显示译文，无缓存或失败显示原文，MUST NOT 自动生成。重启后按开关决定默认展示，不持久化单文档视图选择。编辑、分屏、未保存或模型未就绪时 MUST NOT 自动读取缓存。关闭开关、切换文件/配置或手动翻译后，迟到缓存结果 MUST NOT 覆盖当前内容。强制重译、流式展示和失败/取消回退规则 MUST 保持有效。

#### Scenario: 默认关闭及旧偏好
- **WHEN** 新用户或没有该字段的旧偏好进入技能详情
- **THEN** 开关关闭，先显示原文，不自动读取译文或发起生成；开关值可保存并在重新打开设置或应用后恢复

#### Scenario: 关闭后返回已有译文
- **WHEN** 关闭开关，用户在当前页面翻译后离开再返回相同技能/文件，包括 A→B→A 导航
- **THEN** 先显示原文；手动切换可立即查看会话中保留的译文，不重复生成

#### Scenario: 关闭时后台继续翻译
- **WHEN** 关闭开关，用户离开正在翻译的文件后返回，后台任务仍在进行或已经完成
- **THEN** 原任务继续且不重复发起；当前页面先显示原文，后台完成不得自动切为译文

#### Scenario: 开启后重启恢复缓存译文
- **WHEN** 开关开启且应用重新启动，用户进入有匹配磁盘缓存的 Markdown 页面
- **THEN** 自动显示缓存译文，无模型请求；无匹配缓存或读取失败则显示原文并等待手动翻译

#### Scenario: 开启时保留会话内的原文选择
- **WHEN** 开启开关，用户从缓存译文切回原文，离开文档后在同一应用会话返回
- **THEN** 保持原文选择，不重新读取缓存覆盖用户选择

#### Scenario: 原文默认策略隔离
- **WHEN** 关闭开关的新视图与已有视图订阅同一翻译会话
- **THEN** 新视图先显示原文，不改写其他视图的选择或共享任务结果

#### Scenario: 开启时的缓存加载状态
- **WHEN** 开启开关，进入可翻译的已保存 Markdown 页面，缓存读取尚未完成
- **THEN** 暂缓正文显示，命中后译文直接成为首帧内容，未命中或失败才显示原文；编辑和分屏继续使用原文

#### Scenario: 读取未决及关闭开关
- **WHEN** 开启时的缓存读取尚未返回，用户关闭开关或切换页面/配置
- **THEN** 关闭时立即显示原文，迟到结果不得覆盖原文或新页面；保持开启时命中后直接显示译文，未命中或失败才回落原文

### Requirement: 模型连接与翻译设置分离
模型供应商管理连接与凭据，翻译设置 MUST 仅引用供应商/模型并管理语言、优先显示译文与清缓存。未选择模型 MUST 提供设置入口，MUST NOT 发请求；供应商/模型均须启用。配置入口 MUST 可从详情打开，关闭后保留当前文档；配置成功 MUST NOT 自动触发生成。翻译设置 MUST NOT 显示文档发送至服务商的提示文案。

#### Scenario: 首次配置
- **WHEN** 用户无翻译模型并进入设置完成配置
- **THEN** 返回原文档，由用户再次触发翻译

### Requirement: 设置入口与弹窗导航
设置主页面 MUST 仅显示「模型管理」与「翻译设置」的独立入口卡片及状态摘要，不展开表单。下拉项 MUST 沿用应用自定义菜单与选中标记，标签与控件使用一致间距，MUST NOT 使用系统原生下拉外观。入口与技能详情的翻译设置 MUST 使用同一套带遮罩的详情弹窗。翻译页 MUST 提供语言、模型选择、优先显示译文开关与缓存操作；确认可用模型为零时，MUST 用与下拉栏同尺寸的醒目「去配置」按钮替代模型下拉栏，并在同一弹窗进入模型管理，提供返回翻译设置入口。加载中或读取失败 MUST NOT 被当作无模型。已有可用模型时 MUST 保留下拉栏，不额外显示配置按钮。模型服务也可通过独立入口管理。两个设置入口 MUST 使用不同的按钮图标与文字（模型管理与翻译设置）。供应商编辑在弹窗内切页，不叠加设置详情弹窗。重新打开翻译页 MUST 保留原语言、模型与译文显示偏好并刷新可选模型，MUST NOT 自动选用新增模型或发起翻译。独立进入供应商管理 MUST NOT 要求配置翻译。

#### Scenario: 独立管理连接后重新打开翻译
- **WHEN** 用户关闭翻译选项，通过独立模型管理入口新增连接后再打开翻译选项
- **THEN** 翻译选项重新打开后，原语言与原选用模型不变，新可用模型出现在选项中，由用户决定是否选用

#### Scenario: 独立打开供应商设置
- **WHEN** 用户从设置主页面打开模型供应商
- **THEN** 只展示连接管理，关闭后焦点返回原入口，不展示翻译表单或改变翻译偏好

#### Scenario: 无模型时配置并返回
- **WHEN** 翻译设置没有可用模型，用户点击去配置并保存一个新模型后返回
- **THEN** 在同一弹窗内完成导航，恢复语言与原模型偏好并展示可用模型下拉栏，不自动选用新增模型或发起翻译

### Requirement: 取消与结果身份隔离
请求 MUST 在发起前拥有可取消的身份。离页或切换文件/技能 MUST 仅解除当前视图订阅，不取消已手动发起的翻译；同一应用会话内返回匹配技能、文件、源文、目标语言和有效模型配置时 MUST 接续进度或结果，不重复请求。源文、目标或配置不同的视图 MUST NOT 显示旧任务结果。显式取消或重译 MUST 使旧任务失效并忽略其迟到事件；取消 MUST NOT 报错或提交部分缓存。正常完成提交与取消 MUST 有唯一先后顺序，提交后取消不撤销成功缓存；不承诺供应商服务端停止生成或计费，也不承诺退出应用后恢复在途任务。

#### Scenario: 首块前离开
- **WHEN** 请求注册或发出后尚无首块时用户切换文件或离页
- **THEN** 原任务继续，新文件不展示原任务结果，返回原文件接续原任务而不重复发请求

#### Scenario: 离页期间完成
- **WHEN** 当前视图已卸载，手动翻译成功完成后用户返回相同身份的文件
- **THEN** 当前应用会话保留完成结果，不重复翻译；开启优先显示译文时按会话选择显示结果，关闭时先显示原文并允许手动查看已有译文

#### Scenario: 显式取消及重译
- **WHEN** 用户显式取消，或主动重译替换已有任务
- **THEN** 旧任务即使稍后注册成功或送达事件也不覆盖当前结果；重译保留旧成功译文作为失败或取消时的回退；首段新正文到达后渐进显示新译文

#### Scenario: 同一身份重复启动
- **WHEN** 同一任务正在进行，另一个视图或重复点击再次请求普通翻译
- **THEN** 共享已有任务，不重复发起模型请求
