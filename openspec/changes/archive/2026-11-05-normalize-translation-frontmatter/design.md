# Design

## Context

见 proposal.md。当前 ProtectedMarkdown 使用 YAML 解码值，却用正则定位字节范围回填。Markdown 阅读器也把任意 `---` 子串误作头部终点。

## Goals / Non-Goals

统一头部字段边界的解释，保留语义与源文件；不增加依赖，不改变正文保护和模型请求协议。

## Decisions

- 保存已解析的 YAML 对象，替换 description 后使用现有 serde_yaml 序列化完整头部。放弃正则回填及逐字节排版保留，避免维护另一套 YAML 语法。
- 无字符串 description 或原头部不可解析时，继续整体原样保护，不让模型改写其他字段。
- 前端只把独占一行的关闭分隔符作为头部终点；解析失败保留原始内容，避免静默丢失元数据。

## Risks / Trade-offs

- 译文注释和排版可能变化 → 只规范化翻译缓存，原始 Skill 不动。
- 已有缓存承载旧算法结果 → 升级策略版本，仅在手动翻译时重新请求。

## 翻译任务生命周期

用户确认离页继续。任务与视图解耦：使用既有 QueryClient 持有以技能、文件、源文、目标语言和有效模型配置确定的会话；流式事件更新对应会话，不依赖页面是否挂载。仅手动启动的会话保留至应用会话结束，未翻译草稿随视图回收，避免输入时积累无限缓存。

- 离页只解除订阅，首段前离页也继续注册和请求。返回匹配身份直接接续，不重新请求。
- 显式取消使任务 ID 失效；重译取消旧任务并保留旧成功结果。迟到事件必须匹配当前任务 ID。
- 同一会话的重复启动不发重复请求。其他文档或配置只展示各自结果。
- 保留用户选择原文的状态，完成事件不强制切回译文。
- 不增加任务队列、后台轮询、应用重启恢复或跨窗口同步；后端超时和原子提交继续生效。
