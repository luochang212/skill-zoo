## MODIFIED Requirements

### Requirement: 状态与只读展示
下拉 MUST 提供翻译为当前目标语言、语言选择、翻译设置；有结果时提供原文/译文切换与重译，进行中提供取消。初次翻译等待首段正文时 MUST 在正文区显示旋转加载图标，MUST NOT 展示技能无内容的空状态；收到正文后流式显示，允许查看原文；重译期间保留旧成功译文，成功后替换；用户在生成期间切回原文后，完成 MUST NOT 强制切回译文。译文通过按钮选中态与 tooltip 标识，无常驻模型/AI 文字。编辑或分屏 MUST 使用原文，任何译文 MUST NOT 进入原文草稿或保存路径。当前应用会话已有匹配翻译时重新进入文件 MUST 保留该会话进度、结果与原文/译文选择；没有会话时默认原文，启用缓存译文优先模式时可直接显示有效磁盘缓存。自动读取 MUST NOT 发起模型请求。

#### Scenario: 从译文进入编辑
- **WHEN** 用户在译文视图切到编辑
- **THEN** 编辑器仅显示原文，已有草稿保护继续生效

### Requirement: 取消与结果身份隔离
请求 MUST 在发起前拥有可取消的身份。离页或切换文件/技能 MUST 仅解除当前视图订阅，不取消已手动发起的翻译；同一应用会话内返回匹配技能、文件、源文、目标语言和有效模型配置时 MUST 接续进度或结果，不重复请求。源文、目标或配置不同的视图 MUST NOT 显示旧任务结果。显式取消或重译 MUST 使旧任务失效并忽略其迟到事件；取消 MUST NOT 报错或提交部分缓存。正常完成提交与取消 MUST 有唯一先后顺序，提交后取消不撤销成功缓存；不承诺供应商服务端停止生成或计费，也不承诺退出应用后恢复在途任务。

#### Scenario: 首块前离开
- **WHEN** 请求注册或发出后尚无首块时用户切换文件或离页
- **THEN** 原任务继续，新文件不展示原任务结果，返回原文件接续原任务而不重复发请求

#### Scenario: 离页期间完成
- **WHEN** 当前视图已卸载，手动翻译成功完成后用户返回相同身份的文件
- **THEN** 当前应用会话直接显示完成结果，不要求重新翻译或启用磁盘缓存优先

#### Scenario: 显式取消及重译
- **WHEN** 用户显式取消，或主动重译替换已有任务
- **THEN** 旧任务即使稍后注册成功或送达事件也不覆盖当前结果；重译保留旧成功译文至新结果完成

#### Scenario: 同一身份重复启动
- **WHEN** 同一任务正在进行，另一个视图或重复点击再次请求普通翻译
- **THEN** 共享已有任务，不重复发起模型请求

### Requirement: 受保护内容保真
围栏代码块、行内代码和链接目标 MUST 通过确定性保护保持原文；frontmatter 非 description 字段 MUST 保持语义值；description 字符串值可翻译。有效 frontmatter 的译文 MUST 保持合法 YAML，允许规范化引号、缩进和块样式及移除注释，MUST NOT 修改技能源文件。保护标记缺失、重复或被改写时 MUST 失败且不缓存。同一受保护源文行内的行内标记 MUST 允许为目标语言语序重排；不同源文行、独立代码块和 frontmatter 标记之间的相对顺序 MUST 保留，description 边界 MUST 完整且有序。提示词 MUST 要求自然语言中的路径/命令、Markdown 结构与已为目标语言的内容保持原样，但不得将模型质量目标宣传为所有自然语言命令均可安全执行。

#### Scenario: 模型改坏标记
- **WHEN** 返回结果丢失保护标记
- **THEN** 先弹出修复提示并发起一次定向修复；修复后仍未通过才显示保真失败，保留原文与已有成功结果，不写新缓存

#### Scenario: 行内语序重排
- **WHEN** 同一源文行内的标记都原样出现一次，仅因中文语序改变先后
- **THEN** 成功还原，不发起修复，不将正常译文判为损坏

#### Scenario: 跨行或块级标记移动
- **WHEN** 标记被移至另一源文行的标记之前或越过代码块、frontmatter 边界
- **THEN** 校验拒绝该结构变化，不直接当作成功缓存

#### Scenario: 多段与特殊写法的说明
- **WHEN** 合法 frontmatter 使用含空行的块字符串、多行引号或带引号的 description 键
- **THEN** 完整翻译 description 字符串值，保留 name 与其他字段的语义值，译文头部可正常展示

#### Scenario: 说明包含分隔文本
- **WHEN** description 字符串包含 --- 子串
- **THEN** 阅读器不把字段值截成头部结束符，正常展示元数据与正文

#### Scenario: 原始头部不可解析
- **WHEN** 原始 frontmatter 不是有效 YAML
- **THEN** 翻译整体原样保护该头部，阅读器保留其原始内容，不静默丢弃

### Requirement: 优先显示缓存译文
翻译设置 MUST 提供持久化的「优先显示译文」开关，默认关闭，旧配置缺少该字段时按关闭读取。开启且没有匹配应用会话时，进入可翻译的已保存 Markdown 页面 MUST 仅尝试读取与当前文档内容、目标语言及有效模型配置匹配的缓存；读取未决时 MUST 显示内容加载状态而不先呈现原文，命中则直接显示译文，无缓存或读取失败仍显示原文，MUST NOT 注册翻译任务、调用模型或自动补译。编辑和分屏继续使用原文。用户主动切回原文后 MUST 保留当前页面选择；切换文件/配置或手动开始翻译后，迟到缓存结果 MUST NOT 覆盖当前内容。

#### Scenario: 只有命中缓存才自动显示
- **WHEN** 开启该模式后进入一个有匹配缓存的 Markdown 页面
- **THEN** 直接显示缓存译文，可切回原文，无模型请求；若没有匹配缓存则保留原文并等待手动翻译

#### Scenario: 读取未决不闪烁原文
- **WHEN** 开启该模式后进入页面，缓存读取尚未返回
- **THEN** 内容区保持加载状态，命中后译文直接成为首帧内容，未命中或失败才回落原文

#### Scenario: 旧偏好与迟到结果
- **WHEN** 旧偏好没有缓存显示开关，或缓存读取尚未返回时切换页面/配置或手动翻译
- **THEN** 旧偏好按关闭处理，迟到结果不覆盖新页面或用户操作结果
