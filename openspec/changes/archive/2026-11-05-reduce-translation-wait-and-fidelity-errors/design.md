# Design

## Context

用户已批准默认关闭可关闭的思考模式、不采用并发、降低保真误判。前端只能表现开关可操作或不可操作，不展示未知/不支持/加载文字。证据及试验限制见 proposal 和研究报告。

## Goals / Non-Goals

目标是在现有翻译生命周期内减少首段等待、token 和误判。不会增加并发、分块调度、格式协商或自动重试，不替换整篇 Markdown 保护协议。

## Decisions

- 持久化 Model.thinking 默认为 false，旧文件缺字段可读。模型摘要继续无凭据；偏好进入翻译缓存身份，更新策略版本。
- Rust 用一个无状态的思考参数适配函数，按真实服务域名、协议、已确认模型匹配。先覆盖 DeepSeek Flash/Pro、百炼 Qwen 3.8 和确认支持开关的 Anthropic adaptive 模型；不从未知中转地址或近似模型名推断。该函数同时决定请求参数和 typed IPC 的可操作布尔值，不维护运行时能力状态。未知/固定思考模型不附参数。
- 编辑模型页复用 Switch，作为首项，默认关闭；可操作性通过独立本地 IPC 和 React Query 的配置身份管理，旧结果不影响新 ID。只有确认才提交偏好，取消不改动服务。无能力状态文字或 toast。
- 显式最小连接测试仍使用固定短提示与既有最小预算，在支持时明确关闭思考，避免为探测设置思考预算；不发送文档、不保存配置。
- 保护标记按受保护输入的源文行分组。同组内允许重排；所有标记仍须唯一完整，不同组在输出中的区间必须保持原先先后顺序。代码块与 frontmatter 标记本来各占独立源文行，因此不能越过它们移动行内内容。description 标记也参与结构校验。选择源文行而不是完整 Markdown AST，是为了以小改动修复已复现案例；跨行的更广泛语序变换仍保守拒绝。
- 修复轮数、取消、失败和缓存提交规则不变。不因为能力未知或参数被拒绝自动重试。

## Risks / Trade-offs

- 已确认适配集合保守 → 未覆盖的模型开关不可操作，后端不发送未经确认的字段，不向前端暴露分类。
- 厂商未来变更 → 明确失败并更新映射，不把参数错误包装为静默恢复思考。
- 源文行约束仍可能拒绝跨行语序变化 → 这是保留结构保护的边界，不宣称任意 Markdown 翻译都无损。
- 开关关闭不代表未知或固定思考模型的服务端一定不思考 → 不可操作时不允许用户作出无法执行的设置。

## Migration Plan

配置版本保持 1，以可缺省布尔字段兼容旧配置；旧配置默认关闭。缓存策略升级使旧派生译文不遮蔽新策略，原文件与用户技能均不修改。回滚代码不会破坏技能原文。
