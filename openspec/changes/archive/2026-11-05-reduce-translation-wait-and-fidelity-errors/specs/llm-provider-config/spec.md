## ADDED Requirements

### Requirement: 模型思考偏好
模型 MUST 保存默认关闭的深度思考偏好；旧配置缺字段 MUST 按关闭读取。编辑与添加模型弹窗 MUST 将深度思考开关放在第一个选项，确认才提交，取消不改变草稿。可操作性 MUST 由后端结合服务地址、协议和模型确定，前端仅显示可操作或不可操作的开关，MUST NOT 显示能力分类、查询状态、失败提示或状态 toast。配置身份改变后旧查询 MUST NOT 影响新模型。

后端 MUST 只对已确认支持的服务与模型发送相应思考参数；未知或不支持切换的模型 MUST NOT 发送未经确认的参数，MUST NOT 自动协商或重试。最小连接测试 MUST 保持既有预算并在支持时关闭思考。偏好改变 MUST 隔离翻译缓存。

#### Scenario: 旧配置与取消
- **WHEN** 旧模型缺少思考偏好，用户打开编辑后操作开关并取消
- **THEN** 初始关闭，取消不改变保存配置或服务草稿

#### Scenario: 未知能力与迟到查询
- **WHEN** 模型未知、不可切换或能力查询尚未完成，或 ID 已变化
- **THEN** 开关不可操作且无额外状态文字，旧结果不能启用新 ID 的开关

#### Scenario: 支持的模型
- **WHEN** 对确认支持的服务模型发起翻译
- **THEN** 后端按已保存的默认关闭或显式开启偏好生成对应参数，无隐式失败重试
