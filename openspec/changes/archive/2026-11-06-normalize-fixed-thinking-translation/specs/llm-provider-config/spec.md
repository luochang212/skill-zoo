## MODIFIED Requirements

### Requirement: 模型思考偏好
模型 MUST 保存默认关闭的深度思考偏好；旧配置缺字段 MUST 按关闭读取；该字段表示用户偏好，MUST NOT 将其等同于固定思考模型的实际状态。编辑与添加模型弹窗 MUST 将深度思考开关放在第一个选项，确认才提交，取消不改变草稿。可操作性 MUST 由后端结合服务地址、协议和模型确定，后端 MUST 区分可切换、已确认始终思考与服务默认三种控制模式，前端仅显示可操作或不可操作的开关；已确认始终思考时 MUST 显示开启且不可操作，不因能力查询自动改写保存偏好，MUST NOT 显示能力分类、查询状态、失败提示或状态 toast。配置身份改变后旧查询 MUST NOT 影响新模型。

后端 MUST 只对已确认支持的服务与模型发送相应思考参数；未知或不支持切换的模型 MUST NOT 发送未经确认的参数；已确认的火山 Coding Plan Chat Completions 固定思考模型 glm-5.3-flash 与 glm-5-3-flash-260828 MUST 显式使用 reasoning_effort=low，不将其描述为关闭思考，MUST NOT 自动协商或重试。最小连接测试 MUST 保持既有预算并在支持时关闭思考。偏好改变 MUST 隔离翻译缓存。

#### Scenario: 旧配置与取消
- **WHEN** 旧模型缺少思考偏好，用户打开编辑后操作开关并取消
- **THEN** 初始关闭，取消不改变保存配置或服务草稿

#### Scenario: 未知能力与迟到查询
- **WHEN** 模型未知、不可切换或能力查询尚未完成，或 ID 已变化
- **THEN** 开关不可操作且无额外状态文字，旧结果不能启用新 ID 的开关

#### Scenario: 支持的模型
- **WHEN** 对确认支持的服务模型发起翻译
- **THEN** 后端按已保存的默认关闭或显式开启偏好生成对应参数，无隐式失败重试

#### Scenario: 固定思考模型的轻量翻译
- **WHEN** 用户通过 https://ark.cn-beijing.volces.com/api/coding/v3/ 使用 glm-5.3-flash 或 glm-5-3-flash-260828
- **THEN** 连接探测、正文翻译与定向修复都携带 reasoning_effort=low，编辑器开关呈开启且不可操作，读取能力不修改保存偏好；不匹配的地址、协议和模型保持原参数规则，不延长超时或自动重试

#### Scenario: 固定思考能力的旧结果
- **WHEN** 始终思考能力查询返回前用户已经切换到其他模型或地址
- **THEN** 旧结果不使新配置的开关显示为已确认开启或变得可操作
