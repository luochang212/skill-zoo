## ADDED Requirements

### Requirement: Markdown 链接按阅读上下文导航

技能详情阅读器 MUST 在阅读器内打开相对文件链接，按当前文档目录解析路径。打开技能内文件时 MUST 自动展开文件树中的所有父目录并选中目标文件；用户 MUST 通过文件树切换文档，不提供额外的文档返回按钮。Markdown 文件 MUST 渲染为文档，图片 MUST 使用图片预览，其他文本 MUST 使用文本预览；无法预览的本地文件 MUST 提供现有系统打开入口。

#### Scenario: 嵌套文档与文件树联动
- **WHEN** 用户从技能详情打开 `references/guide.md`，再打开其中的 `./example.md`
- **THEN** 阅读器依次显示两个文件，第二个路径为 `references/example.md`，文件树展开对应父目录并选中当前文件，不新增文档返回按钮

#### Scenario: 标题定位
- **WHEN** 用户在技能详情点击 `#标题` 或 `guide.md#标题`
- **THEN** 阅读器定位当前或目标文档内的对应标题，重复标题具有不同标识

#### Scenario: 本地安全边界
- **WHEN** 链接包含向父目录导航、编码路径或符号链接
- **THEN** 路径解析允许仍在技能根目录内的父目录导航，后端 MUST 拒绝越出技能根目录的目标

#### Scenario: 外部与不支持的协议
- **WHEN** 用户点击 HTTP、HTTPS 或 mailto 链接
- **THEN** 阅读器交给系统处理，其他协议、绝对磁盘路径及越界路径不可直接打开

#### Scenario: 发现页预览
- **WHEN** 用户在发现页查看技能 Markdown 预览
- **THEN** 链接仅显示其内容，不提供点击或导航行为

#### Scenario: 仓库 README 链接在浏览器打开
- **WHEN** 用户点击仓库 README 中的相对文件、标题锚点或外部链接
- **THEN** 阅读器 MUST 交给系统打开，相对文件与锚点指向 GitHub 同仓库同分支的页面，MUST NOT 在侧边栏读取目标文档或提供文档返回导航

#### Scenario: 目录展开后仍可手动收起
- **WHEN** 文件链接已展开目标文件的父目录，用户随后手动收起该目录
- **THEN** 相同文件保持选中时目录不会被强制重新展开，切换到另一个内部文件时重新展开其父目录
