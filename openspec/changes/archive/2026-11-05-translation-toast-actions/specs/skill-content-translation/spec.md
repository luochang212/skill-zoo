## MODIFIED Requirements

### Requirement: 状态与只读展示
下拉 MUST 提供翻译为当前目标语言、语言选择、翻译设置；有结果时提供原文/译文切换与重译，翻译按钮右侧在翻译及自动修复中显示中止按钮，终止失败后显示重试按钮，其余状态不显示；中止从下拉移至该按钮，按钮只显示图标，悬停提示和可访问名称保留动作文字。初次翻译等待首段正文时 MUST 保留可阅读原文，MUST NOT 用加载图标或空状态替换正文；收到正文后流式显示，允许查看原文；重译期间保留旧成功译文，成功后替换；用户在生成期间切回原文后，完成 MUST NOT 强制切回译文。译文通过按钮选中态与 tooltip 标识，无常驻模型/AI 文字。编辑或分屏 MUST 使用原文，任何译文 MUST NOT 进入原文草稿或保存路径。当前应用会话已有匹配翻译时重新进入文件 MUST 保留该会话进度、结果与原文/译文选择；没有会话时默认原文，启用缓存译文优先模式时可直接显示有效磁盘缓存。自动读取 MUST NOT 发起模型请求。

#### Scenario: 从译文进入编辑
- **WHEN** 用户在译文视图切到编辑
- **THEN** 编辑器仅显示原文，已有草稿保护继续生效

### Requirement: 完成与失败判定
只有明确正常完成且非空、通过保护校验的输出 MUST 被当作成功。截断、拒绝、未知/缺失终止原因、异常断流 MUST 通过 Toast 提示错误并提供工具栏手动重试，MUST NOT 缓存；除保真失败后的至多一次定向修复外，MUST NOT 自动重试或弹出错误对话框。定向修复 MUST 在发起前弹出可见提示 Toast，仅重译含损坏标记的源文片段并以完整未受损标记组为锚点确定性拼接，组内译文和合法重排 MUST 原样保留，MUST NOT 用组内单个标记切割；修复规划 MUST 与最终校验共用源文行分组规则，跨组移位或重复标记的所有出现位置 MUST 被损坏区域覆盖，必要时合并相邻损坏范围，修复结果重新整体通过保真校验方可成功；盲目原样重试仍 MUST NOT 自动执行。请求 MUST 有首响应、流空闲与总超时。源文上限 MUST 为 51,200 UTF-8 字节，超过时不请求；输出也须有界。

#### Scenario: 输出截断
- **WHEN** 服务正常结束连接但终止原因是 token 上限
- **THEN** 不显示完整成功，不覆盖旧成功缓存，提示调整模型输出上限后重试

#### Scenario: 漏标记与健康行内重排同时出现
- **WHEN** 元数据标记缺失，但后续完整行内组仅发生合法重排
- **THEN** 仅修复必要的损坏区域，原样保留健康组，拼接不得重复插入其中的标记

#### Scenario: 坏标记跨组出现
- **WHEN** 不完整或重复标记出现在其他组的前后或内部
- **THEN** 修复区域覆盖其全部出现位置，不把含有这些坏标记的范围作为健康锚点保留

## ADDED Requirements

### Requirement: 翻译通知与上下文操作
技能详情翻译任务失败及翻译配置读写错误 MUST 仅通过 Toast 通知，不渲染正文条幅。任务失败通知 MUST 由共享会话发出，同一终止事件不得重复通知。任务提示 MUST 简短单句，可使用发起时已有技能名称前缀，不增加来源查询或路径、模型、任务编号等附加说明。翻译分体按钮右侧 MUST 在进行中显示中止、终止失败后显示重试，其余状态隐藏；自动修复仍属进行中。按钮 MUST 仅显示图标，以悬停提示及可访问名称表达动作。编辑、未保存或配置读取未决时重试 MUST 遵守原翻译可用性限制，中止不受编辑模式限制。

#### Scenario: 失败与重试
- **WHEN** 翻译任务终止失败并收到重复失败事件
- **THEN** 仅通知一次错误 Toast，保留可阅读内容，不插入条幅；工具栏显示重试，点击后变为中止

#### Scenario: 修复和结束
- **WHEN** 翻译进入自动修复，或最终成功或手动中止
- **THEN** 修复中只显示中止，不显示重试；成功或中止后隐藏上下文按钮，不将中止作为失败通知

#### Scenario: 配置失败与编辑模式
- **WHEN** 配置读取失败，或正在编辑原文且有在途翻译任务
- **THEN** 配置失败只通过 Toast 告知；编辑模式允许中止在途任务，但禁止对草稿直接重试

#### Scenario: 并行任务的精简反馈
- **WHEN** 用户切换页面后，多个后台翻译任务返回失败或修复提示
- **THEN** 每条提示使用对应任务发起时的上下文；有现成名称时可简短标识，没有时使用通用短提示，不套用当前页面名称
