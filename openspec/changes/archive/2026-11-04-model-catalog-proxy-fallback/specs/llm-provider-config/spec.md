## MODIFIED Requirements

### Requirement: 公开模型目录识别
智能识别 MUST 通过 Rust IPC 读取 Models.dev 的固定匿名 JSON 目录，MUST NOT 上传 API Key、请求头或文档。目录按内存 TTL 缓存，限定请求时限与响应体大小。匹配 MUST 依次尝试服务地址及完整模型 ID、跨供应商完整 ID、去除命名空间后的精确末段 ID；同级候选的有效推荐参数一致时才回填，冲突或无效时不回填且不降级。MUST NOT 使用子串或型号近似匹配，不改变请求地址或模型 ID；目录未收录或网络失败 MUST 保留手动编辑与确认。公开目录只提供参考，不验证模型在当前账号可用性。

#### Scenario: 自定义模型未识别
- **WHEN** 模型 ID 无可用匹配、候选冲突，或公开目录不可达
- **THEN** 静默保留手动填写与确认，不显示失败/未匹配提示或 toast，不改用其他模型

#### Scenario: 中转与命名空间模型
- **WHEN** 中转或 Coding Plan 地址未命中目录，但完整模型 ID 或去除命名空间后的精确 ID 有一致的推荐参数
- **THEN** 回填参数，实际地址与模型 ID 保持用户输入

#### Scenario: 优先级与候选冲突
- **WHEN** 当前服务有精确匹配，或较高优先级候选参数冲突
- **THEN** 优先采用当前服务参数；冲突时保持手动编辑，不从较低优先级选择其他值
