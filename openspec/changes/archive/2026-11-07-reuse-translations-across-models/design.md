# Design

## Context
缓存键及前端会话身份都包含生成配置；缓存读取命令也先校验当前模型。已有测试证实更改服务地址导致缓存未命中。ADR 1 的技能协议不包含这些翻译私有文件。

## Goals / Non-Goals
成功译文跨配置复用；新生成仍严格校验配置。用户明确要求不做旧格式迁移，不引入扫描、索引、sidecar 或配置选项。

## Decisions
- 缓存键仅哈希策略版本、语言、原文；成功写入仍走现有原子提交与清空 epoch，失败/取消不写。
- 读取缓存先验证源文件和目标语言；生成路径先尝试共享缓存，再要求可用模型。强制重译仍先验证模型。
- 会话身份仅包含文件身份、原文、目标语言；当前模型留在请求闭包供下一次生成使用，不影响已生成结果或后台任务。
- 保持默认原文偏好；无模型的手动按钮先尝试只读缓存，未命中再打开设置。自动读取不再依赖模型。

## Risks / Trade-offs
- 不迁移意味着旧哈希缓存不会被新键命中；保留文件，用户可按需重译。此取舍由用户明确要求，以避免新发布阶段的迁移维护成本。
- 不同模型覆盖同一成功缓存是预期；只有显式强制重译成功才替换旧结果，不提供版本选择。
- 新键无法被旧版识别；不修改技能文件、配置或本地协议。

## Verification
- 改动前的 hook 回归测试复现：模型切换后成功译文变为空；改动后保留译文及原文选择。
- 前端全量：`bun run test --maxWorkers=2`，52 文件、474 测试通过。默认并发首跑存在超时及旧请求字段断言；更新字段断言后以受限并发完整复跑通过，不放宽超时。
- Rust 翻译相关：`cargo test --features test-helpers --manifest-path src-tauri/Cargo.toml --lib translation::`，26 测试通过。真实命令路径验证无配置、禁用配置、损坏配置的缓存读取、源文/语言隔离、成功提交与强制重译失败保留旧缓存，推理使用本地 mock 服务。
- 类型检查、lint、前端格式与 Rust 格式检查通过。未调用付费模型、未操作用户真实缓存；无迁移。
- Rust 全量命令通过：319 单元测试、60 集成测试通过，3 项既有测试忽略；文档测试通过。`cargo clippy --manifest-path src-tauri/Cargo.toml --features test-helpers -- -D warnings` 通过。
- 最终生产构建通过；主规格与两个 delta 完整对齐，OpenSpec 严格校验与 ADR 校验通过。
