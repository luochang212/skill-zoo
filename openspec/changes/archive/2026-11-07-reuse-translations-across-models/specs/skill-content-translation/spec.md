## MODIFIED Requirements

### Requirement: 优先显示缓存译文
翻译设置 MUST 提供持久化的「优先显示译文」开关，默认关闭，缺字段按关闭读取。关闭时每次进入 MUST 先显示原文，即使共享会话已有译文或后台任务；当前页面手动操作可显示已有结果，不丢弃缓存或中断任务。开启时 MUST 恢复会话选择；无匹配会话时自动读取有效磁盘缓存，命中显示译文，无缓存或失败显示原文，MUST NOT 自动生成。重启后按开关决定默认展示，不持久化单文档视图选择。编辑、分屏或未保存时 MUST NOT 自动读取缓存；供应商或模型未就绪 MUST NOT 阻止读取成功译文。关闭开关、切换文件/语言或手动翻译后，迟到缓存结果 MUST NOT 覆盖当前内容。强制重译、流式展示和失败/取消回退规则 MUST 保持有效。

#### Scenario: 默认关闭及旧偏好
- **WHEN** 新用户或没有该字段的旧偏好进入技能详情
- **THEN** 开关关闭，先显示原文，不自动读取译文或发起生成；开关值可保存并在重新打开设置或应用后恢复

#### Scenario: 关闭后返回已有译文
- **WHEN** 关闭开关，用户在当前页面翻译后离开再返回相同技能/文件，包括 A→B→A 导航
- **THEN** 先显示原文；手动切换可立即查看会话中保留的译文，不重复生成

#### Scenario: 关闭时后台继续翻译
- **WHEN** 关闭开关，用户离开正在翻译的文件后返回，后台任务仍在进行或已经完成
- **THEN** 原任务继续且不重复发起；当前页面先显示原文，后台完成不得自动切为译文

#### Scenario: 开启后重启恢复缓存译文
- **WHEN** 开关开启且应用重新启动，用户进入有匹配磁盘缓存的 Markdown 页面
- **THEN** 自动显示缓存译文，无模型请求；无匹配缓存或读取失败则显示原文并等待手动翻译

#### Scenario: 开启时保留会话内的原文选择
- **WHEN** 开启开关，用户从缓存译文切回原文，离开文档后在同一应用会话返回
- **THEN** 保持原文选择，不重新读取缓存覆盖用户选择

#### Scenario: 原文默认策略隔离
- **WHEN** 关闭开关的新视图与已有视图订阅同一翻译会话
- **THEN** 新视图先显示原文，不改写其他视图的选择或共享任务结果

#### Scenario: 开启时的缓存加载状态
- **WHEN** 开启开关，进入可翻译的已保存 Markdown 页面，缓存读取尚未完成
- **THEN** 暂缓正文显示，命中后译文直接成为首帧内容，未命中或失败才显示原文；编辑和分屏继续使用原文

#### Scenario: 读取未决及关闭开关
- **WHEN** 开启时的缓存读取尚未返回，用户关闭开关或切换页面/语言
- **THEN** 关闭时立即显示原文，迟到结果不得覆盖原文或新页面；保持开启时命中后直接显示译文，未命中或失败才回落原文

#### Scenario: 切换或停用模型
- **WHEN** 已有当前原文及目标语言的成功译文，用户切换供应商、模型或输出参数，或停用原供应商
- **THEN** 已有译文与当前会话选择保持可用，不自动生成，不中断在途任务

#### Scenario: 无模型时手动读取
- **WHEN** 优先显示译文关闭，模型未就绪，用户点击翻译且存在匹配缓存
- **THEN** 显示缓存译文，不要求配置模型；没有缓存才打开模型设置

### Requirement: 模型连接与翻译设置分离
模型供应商管理连接与凭据，翻译设置 MUST 仅引用供应商/模型并管理语言、优先显示译文与清缓存。生成新译文前 MUST 选择已启用供应商和模型，否则提供设置入口且不发生成请求；读取成功译文不依赖模型配置。配置入口 MUST 可从详情打开，关闭后保留当前文档；配置成功 MUST NOT 自动触发生成。翻译设置 MUST NOT 显示文档发送至服务商的提示文案。

#### Scenario: 首次配置
- **WHEN** 用户无翻译模型并进入设置完成配置
- **THEN** 返回原文档，由用户再次触发翻译

### Requirement: 缓存与重新翻译
缓存 MUST 仅由目标语言、源文及翻译策略版本决定，不含供应商、协议、URL、模型、输出参数、技能/文件 ID 或 API Key；相同内容与目标语言可共享。只在成功提交后原子写入应用缓存，MUST NOT 修改技能文件。重译 MUST 跳过旧缓存读取但保留旧条目至新结果成功。清空 MUST 先在原按钮将「清空」改为「确认」，再次激活才执行；确认状态 MUST 更醒目，且切换前后按钮形状与尺寸 MUST 保持一致。退出翻译设置后重新进入，以及一次清空操作结束后，按钮 MUST 恢复「清空」。清空 MUST 不影响其他数据，清空前已在途任务 MUST NOT 将结果写回缓存。

#### Scenario: 重译失败
- **WHEN** 缓存已有成功译文，用户重译失败
- **THEN** 旧译文和旧缓存仍可用

#### Scenario: 强制重译渐进显示
- **WHEN** 用户对已有成功译文（包括自动读取的缓存译文）选择重新翻译
- **THEN** 请求必须强制跳过旧缓存，不再次读取缓存或以旧缓存结束任务；首段非空新预览到达后逐步显示新译文，空预览不清空旧内容，最终成功后更新成功结果；失败或取消恢复旧成功译文与既有缓存

#### Scenario: 清空按钮二次确认
- **WHEN** 用户第一次激活清空按钮
- **THEN** 只将按钮文案改为确认，不清理缓存；再次激活才清空，退出重入时确认状态重置

#### Scenario: 清空时有在途请求
- **WHEN** 用户清空缓存后旧请求完成
- **THEN** 结果可供本次查看，但不会回填已清空的缓存

#### Scenario: 原文或语言变化
- **WHEN** 源文或目标语言改变
- **THEN** 不复用另一原文或另一目标语言的缓存

#### Scenario: 跨模型重译
- **WHEN** 已有成功译文，用户切换模型并显式重译
- **THEN** 使用当前模型生成，只有成功后才替换共享缓存；失败或取消保留旧译文
