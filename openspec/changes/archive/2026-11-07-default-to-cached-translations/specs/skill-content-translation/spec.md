## MODIFIED Requirements

### Requirement: 状态与只读展示
下拉 MUST 提供翻译为当前目标语言、语言选择、翻译设置；有结果时提供原文/译文切换与重译，翻译按钮右侧在翻译及自动修复中显示中止按钮，终止失败后显示重试按钮，其余状态不显示；中止从下拉移至该按钮，按钮只显示图标，悬停提示和可访问名称保留动作文字。初次翻译等待首段正文时 MUST 保留可阅读原文，MUST NOT 用加载图标或空状态替换正文；收到正文后流式显示，允许查看原文；重译期间保留旧成功译文，成功后替换；用户在生成期间切回原文后，完成 MUST NOT 强制切回译文。译文通过按钮选中态与 tooltip 标识，无常驻模型/AI 文字。编辑或分屏 MUST 使用原文，任何译文 MUST NOT 进入原文草稿或保存路径。当前应用会话已有匹配翻译时重新进入文件 MUST 保留该会话进度、结果与原文/译文选择；没有匹配会话时 MUST 自动尝试读取并显示有效磁盘缓存，无缓存或读取失败时显示原文。自动读取 MUST NOT 发起模型请求。

#### Scenario: 从译文进入编辑
- **WHEN** 用户在译文视图切到编辑
- **THEN** 编辑器仅显示原文，已有草稿保护继续生效

### Requirement: 优先显示缓存译文
翻译设置 MUST NOT 提供「优先显示译文」开关或保存该偏好。没有匹配应用会话时，进入可翻译的已保存 Markdown 页面 MUST 自动尝试读取与当前文档内容、目标语言及有效模型配置匹配的磁盘缓存，包括重启应用后；读取未决时 MUST 显示内容加载状态而不先呈现原文，命中则直接显示译文，无缓存或读取失败仍显示原文，MUST NOT 注册翻译任务、调用模型或自动补译。编辑、分屏、未保存草稿与模型未就绪时 MUST NOT 自动读取缓存；编辑和分屏继续使用原文。用户主动切回原文后 MUST 在当前应用会话保留该文档的选择，包括离开后返回；重启后不持久化视图选择，仍按有效缓存默认显示译文。切换文件/配置或手动开始翻译后，迟到缓存结果 MUST NOT 覆盖当前内容。

#### Scenario: 重启后恢复缓存译文
- **WHEN** 应用重新启动，用户进入有匹配磁盘缓存的 Markdown 页面
- **THEN** 自动显示缓存译文，可切回原文，无模型请求；若没有匹配缓存则保留原文并等待手动翻译

#### Scenario: 保留会话内的原文选择
- **WHEN** 用户从缓存译文切回原文，离开文档后在同一应用会话返回
- **THEN** 保持原文选择，不重新读取缓存覆盖用户选择

#### Scenario: 读取未决不闪烁原文
- **WHEN** 进入可翻译页面，缓存读取尚未返回
- **THEN** 内容区保持加载状态，命中后译文直接成为首帧内容，未命中或失败才回落原文

#### Scenario: 迟到结果与不可读取状态
- **WHEN** 缓存读取尚未返回时切换页面/配置或手动翻译，或当前处于编辑、分屏、未保存或模型未就绪状态
- **THEN** 迟到结果不覆盖新页面或用户操作结果，不可读取状态不自动读取缓存或发起生成
