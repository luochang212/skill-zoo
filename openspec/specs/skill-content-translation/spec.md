# skill-content-translation Specification

## Purpose

定义用户在技能详情阅读当前 Markdown 文件时的手动翻译行为，覆盖语言与模型偏好、工具栏呈现、任务生命周期、内容保护、缓存及失败恢复，始终保持技能原始文件与编辑草稿独立。

## Requirements

### Requirement: 按当前文件手动翻译
本地技能详情 MUST 支持当前打开的 SKILL.md 及技能目录内其他 `.md` 文件，含只读、插件、外部导入和归档来源。MUST NOT 自动、递归、批量翻译或抓取外部链接；仓库远程预览与新建未保存技能不在本能力范围。未保存或正在保存的当前文件 MUST 提示先保存，不发送草稿或与当前显示不一致的磁盘内容。

#### Scenario: 多个参考文件
- **WHEN** 技能有大量 references Markdown，用户手动翻译其中一篇
- **THEN** 只读取与翻译该篇，不产生其他文件的请求

### Requirement: 工具栏翻译入口
翻译 MUST 使用紧跟查看/编辑/分屏右侧的分体按钮，左侧约 80% 宽度含 Languages 图标与操作文字，首次点击触发翻译，已有译文时切换原文/译文；右侧约 20% 宽度为独立下箭头菜单触发区，两区之间使用细分隔线；高度、圆角、字号与图标匹配现有工具栏，可用细分隔线。MUST 使用中性色，MUST NOT 放在 Skill 管理区或提供右键翻译。编辑/分屏时保留位置但禁用并提示切换到查看；非 Markdown 不显示。

#### Scenario: 只读技能
- **WHEN** 用户查看只读技能的 Markdown
- **THEN** 查看控件旁仍显示翻译入口，不依赖编辑权限

### Requirement: 状态与只读展示
下拉 MUST 提供翻译为当前目标语言、语言选择、翻译设置；有结果时提供原文/译文切换与重译，翻译按钮右侧在翻译及自动修复中显示中止按钮，终止失败后显示重试按钮，其余状态不显示；中止从下拉移至该按钮，按钮只显示图标，悬停提示和可访问名称保留动作文字。初次翻译等待首段正文时 MUST 保留可阅读原文，MUST NOT 用加载图标或空状态替换正文；收到正文后流式显示，允许查看原文；重译等待首段新正文时保留旧成功译文，收到非空预览后 MUST 渐进显示新译文；重译失败或取消 MUST 恢复旧成功译文，只有成功后才替换成功结果与磁盘缓存；用户在生成期间切回原文后，完成 MUST NOT 强制切回译文。译文通过按钮选中态与 tooltip 标识，无常驻模型/AI 文字。编辑或分屏 MUST 使用原文，任何译文 MUST NOT 进入原文草稿或保存路径。当前会话的任务与结果 MUST 保留；重新进入时的正文展示 MUST 遵循「优先显示译文」偏好。自动读取 MUST NOT 发起模型请求。

#### Scenario: 从译文进入编辑
- **WHEN** 用户在译文视图切到编辑
- **THEN** 编辑器仅显示原文，已有草稿保护继续生效

### Requirement: 优先显示缓存译文
翻译设置 MUST 提供持久化的「优先显示译文」开关，默认关闭，缺字段按关闭读取。关闭时每次进入 MUST 先显示原文，即使共享会话已有译文或后台任务；当前页面手动操作可显示已有结果，不丢弃缓存或中断任务。开启时 MUST 恢复会话选择；无匹配会话时自动读取有效磁盘缓存，命中显示译文，无缓存或失败显示原文，MUST NOT 自动生成。重启后按开关决定默认展示，不持久化单文档视图选择。编辑、分屏、未保存或模型未就绪时 MUST NOT 自动读取缓存。关闭开关、切换文件/配置或手动翻译后，迟到缓存结果 MUST NOT 覆盖当前内容。强制重译、流式展示和失败/取消回退规则 MUST 保持有效。

#### Scenario: 默认关闭及旧偏好
- **WHEN** 新用户或没有该字段的旧偏好进入技能详情
- **THEN** 开关关闭，先显示原文，不自动读取译文或发起生成；开关值可保存并在重新打开设置或应用后恢复

#### Scenario: 关闭后返回已有译文
- **WHEN** 关闭开关，用户在当前页面翻译后离开再返回相同技能/文件，包括 A→B→A 导航
- **THEN** 先显示原文；手动切换可立即查看会话中保留的译文，不重复生成

#### Scenario: 关闭时后台继续翻译
- **WHEN** 关闭开关，用户离开正在翻译的文件后返回，后台任务仍在进行或已经完成
- **THEN** 原任务继续且不重复发起；当前页面先显示原文，后台完成不得自动切为译文

#### Scenario: 开启后重启恢复缓存译文
- **WHEN** 开关开启且应用重新启动，用户进入有匹配磁盘缓存的 Markdown 页面
- **THEN** 自动显示缓存译文，无模型请求；无匹配缓存或读取失败则显示原文并等待手动翻译

#### Scenario: 开启时保留会话内的原文选择
- **WHEN** 开启开关，用户从缓存译文切回原文，离开文档后在同一应用会话返回
- **THEN** 保持原文选择，不重新读取缓存覆盖用户选择

#### Scenario: 原文默认策略隔离
- **WHEN** 关闭开关的新视图与已有视图订阅同一翻译会话
- **THEN** 新视图先显示原文，不改写其他视图的选择或共享任务结果

#### Scenario: 开启时的缓存加载状态
- **WHEN** 开启开关，进入可翻译的已保存 Markdown 页面，缓存读取尚未完成
- **THEN** 暂缓正文显示，命中后译文直接成为首帧内容，未命中或失败才显示原文；编辑和分屏继续使用原文

#### Scenario: 读取未决及关闭开关
- **WHEN** 开启时的缓存读取尚未返回，用户关闭开关或切换页面/配置
- **THEN** 关闭时立即显示原文，迟到结果不得覆盖原文或新页面；保持开启时命中后直接显示译文，未命中或失败才回落原文

### Requirement: 目标语言偏好
翻译语言 MUST 独立于界面语言，支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语。没有已保存偏好时 MUST 用设备首选语言匹配，其次界面语言，最后英语；读取语言不请求敏感权限，不发送完整语言偏好列表。用户在菜单或设置中修改 MUST 持久化，后续系统/界面变化 MUST NOT 覆盖。

#### Scenario: 繁体设备语言
- **WHEN** 无翻译偏好且设备语言为 zh-TW
- **THEN** 默认繁体中文；用户修改后重新打开仍使用所选语言

### Requirement: 模型连接与翻译设置分离
模型供应商管理连接与凭据，翻译设置 MUST 仅引用供应商/模型并管理语言、优先显示译文与清缓存。未选择模型 MUST 提供设置入口，MUST NOT 发请求；供应商/模型均须启用。配置入口 MUST 可从详情打开，关闭后保留当前文档；配置成功 MUST NOT 自动触发生成。翻译设置 MUST NOT 显示文档发送至服务商的提示文案。

#### Scenario: 首次配置
- **WHEN** 用户无翻译模型并进入设置完成配置
- **THEN** 返回原文档，由用户再次触发翻译

### Requirement: 设置入口与弹窗导航
设置主页面 MUST 仅显示「模型管理」与「翻译设置」的独立入口卡片及状态摘要，不展开表单。下拉项 MUST 沿用应用自定义菜单与选中标记，标签与控件使用一致间距，MUST NOT 使用系统原生下拉外观。入口与技能详情的翻译设置 MUST 使用同一套带遮罩的详情弹窗。翻译页 MUST 提供语言、模型选择、优先显示译文开关与缓存操作；确认可用模型为零时，MUST 用与下拉栏同尺寸的醒目「去配置」按钮替代模型下拉栏，并在同一弹窗进入模型管理，提供返回翻译设置入口。加载中或读取失败 MUST NOT 被当作无模型。已有可用模型时 MUST 保留下拉栏，不额外显示配置按钮。模型服务也可通过独立入口管理。两个设置入口 MUST 使用不同的按钮图标与文字（模型管理与翻译设置）。供应商编辑在弹窗内切页，不叠加设置详情弹窗。重新打开翻译页 MUST 保留原语言、模型与译文显示偏好并刷新可选模型，MUST NOT 自动选用新增模型或发起翻译。独立进入供应商管理 MUST NOT 要求配置翻译。

#### Scenario: 独立管理连接后重新打开翻译
- **WHEN** 用户关闭翻译选项，通过独立模型管理入口新增连接后再打开翻译选项
- **THEN** 翻译选项重新打开后，原语言与原选用模型不变，新可用模型出现在选项中，由用户决定是否选用

#### Scenario: 独立打开供应商设置
- **WHEN** 用户从设置主页面打开模型供应商
- **THEN** 只展示连接管理，关闭后焦点返回原入口，不展示翻译表单或改变翻译偏好

#### Scenario: 无模型时配置并返回
- **WHEN** 翻译设置没有可用模型，用户点击去配置并保存一个新模型后返回
- **THEN** 在同一弹窗内完成导航，恢复语言与原模型偏好并展示可用模型下拉栏，不自动选用新增模型或发起翻译

### Requirement: 取消与结果身份隔离
请求 MUST 在发起前拥有可取消的身份。离页或切换文件/技能 MUST 仅解除当前视图订阅，不取消已手动发起的翻译；同一应用会话内返回匹配技能、文件、源文、目标语言和有效模型配置时 MUST 接续进度或结果，不重复请求。源文、目标或配置不同的视图 MUST NOT 显示旧任务结果。显式取消或重译 MUST 使旧任务失效并忽略其迟到事件；取消 MUST NOT 报错或提交部分缓存。正常完成提交与取消 MUST 有唯一先后顺序，提交后取消不撤销成功缓存；不承诺供应商服务端停止生成或计费，也不承诺退出应用后恢复在途任务。

#### Scenario: 首块前离开
- **WHEN** 请求注册或发出后尚无首块时用户切换文件或离页
- **THEN** 原任务继续，新文件不展示原任务结果，返回原文件接续原任务而不重复发请求

#### Scenario: 离页期间完成
- **WHEN** 当前视图已卸载，手动翻译成功完成后用户返回相同身份的文件
- **THEN** 当前应用会话保留完成结果，不重复翻译；开启优先显示译文时按会话选择显示结果，关闭时先显示原文并允许手动查看已有译文

#### Scenario: 显式取消及重译
- **WHEN** 用户显式取消，或主动重译替换已有任务
- **THEN** 旧任务即使稍后注册成功或送达事件也不覆盖当前结果；重译保留旧成功译文作为失败或取消时的回退；首段新正文到达后渐进显示新译文

#### Scenario: 同一身份重复启动
- **WHEN** 同一任务正在进行，另一个视图或重复点击再次请求普通翻译
- **THEN** 共享已有任务，不重复发起模型请求

### Requirement: 受保护内容保真
围栏代码块、行内代码和链接目标 MUST 通过确定性保护保持原文；frontmatter 非 description 字段 MUST 保持语义值；description 字符串值可翻译。有效 frontmatter 的译文 MUST 保持合法 YAML，允许规范化引号、缩进和块样式及移除注释，MUST NOT 修改技能源文件。保护标记缺失、重复或被改写时 MUST 失败且不缓存。同一受保护源文行内的行内标记 MUST 允许为目标语言语序重排；不同源文行、独立代码块和 frontmatter 标记之间的相对顺序 MUST 保留，description 边界 MUST 完整且有序。提示词 MUST 要求自然语言中的路径/命令、Markdown 结构与已为目标语言的内容保持原样，但不得将模型质量目标宣传为所有自然语言命令均可安全执行。

#### Scenario: 模型改坏标记
- **WHEN** 返回结果丢失保护标记
- **THEN** 先弹出修复提示并发起一次定向修复；修复后仍未通过才显示保真失败，保留原文与已有成功结果，不写新缓存

#### Scenario: 行内语序重排
- **WHEN** 同一源文行内的标记都原样出现一次，仅因中文语序改变先后
- **THEN** 成功还原，不发起修复，不将正常译文判为损坏

#### Scenario: 跨行或块级标记移动
- **WHEN** 标记被移至另一源文行的标记之前或越过代码块、frontmatter 边界
- **THEN** 校验拒绝该结构变化，不直接当作成功缓存

#### Scenario: 多段与特殊写法的说明
- **WHEN** 合法 frontmatter 使用含空行的块字符串、多行引号或带引号的 description 键
- **THEN** 完整翻译 description 字符串值，保留 name 与其他字段的语义值，译文头部可正常展示

#### Scenario: 说明包含分隔文本
- **WHEN** description 字符串包含 --- 子串
- **THEN** 阅读器不把字段值截成头部结束符，正常展示元数据与正文

#### Scenario: 原始头部不可解析
- **WHEN** 原始 frontmatter 不是有效 YAML
- **THEN** 翻译整体原样保护该头部，阅读器保留其原始内容，不静默丢弃

#### Scenario: 头部起点与模型额外包装
- **WHEN** 有 frontmatter 的文档带 BOM 或前导空白，或模型在头部标记前插入非空白前言或代码包装
- **THEN** 识别并保护源头部；额外包装输出不能作为成功译文缓存，不通过保真校验

#### Scenario: 代码块内部的引用式围栏
- **WHEN** 代码块内部出现不同引用层级的围栏文本
- **THEN** 不将其当作当前代码块的关闭标记，代码内容保持保护；同层级的正确关闭标记仍生效

### Requirement: 完成与失败判定
只有明确正常完成且非空、通过保护校验的输出 MUST 被当作成功。截断、拒绝、未知/缺失终止原因、异常断流 MUST 通过 Toast 提示错误并提供工具栏手动重试，MUST NOT 缓存；除保真失败后的至多一次定向修复外，MUST NOT 自动重试或弹出错误对话框。定向修复 MUST 在发起前弹出可见提示 Toast，仅重译含损坏标记的源文片段并以完整未受损标记组为锚点确定性拼接，组内译文和合法重排 MUST 原样保留，MUST NOT 用组内单个标记切割；修复规划 MUST 与最终校验共用源文行分组规则，跨组移位或重复标记的所有出现位置 MUST 被损坏区域覆盖，必要时合并相邻损坏范围，修复结果重新整体通过保真校验方可成功；盲目原样重试仍 MUST NOT 自动执行。请求 MUST 有首响应、流空闲与总超时。源文上限 MUST 为 51,200 UTF-8 字节，超过时不请求；输出也须有界。

#### Scenario: 输出截断
- **WHEN** 服务正常结束连接但终止原因是 token 上限
- **THEN** 不显示完整成功，不覆盖旧成功缓存，提示调整模型输出上限后重试

#### Scenario: 漏标记与健康行内重排同时出现
- **WHEN** 元数据标记缺失，但后续完整行内组仅发生合法重排
- **THEN** 仅修复必要的损坏区域，原样保留健康组，拼接不得重复插入其中的标记

#### Scenario: 坏标记跨组出现
- **WHEN** 不完整或重复标记出现在其他组的前后或内部
- **THEN** 修复区域覆盖其全部出现位置，不把含有这些坏标记的范围作为健康锚点保留

### Requirement: 缓存与重新翻译
缓存 MUST 由有效协议、规范化 URL、模型、输出参数、目标语言、源文及翻译策略版本决定，不含技能/文件 ID 或 API Key；同有效配置可共享。只在成功提交后原子写入应用缓存，MUST NOT 修改技能文件。重译 MUST 跳过旧缓存读取但保留旧条目至新结果成功。清空 MUST 先在原按钮将「清空」改为「确认」，再次激活才执行；确认状态 MUST 更醒目，且切换前后按钮形状与尺寸 MUST 保持一致。退出翻译设置后重新进入，以及一次清空操作结束后，按钮 MUST 恢复「清空」。清空 MUST 不影响其他数据，清空前已在途任务 MUST NOT 将结果写回缓存。

#### Scenario: 重译失败
- **WHEN** 缓存已有成功译文，用户重译失败
- **THEN** 旧译文和旧缓存仍可用

#### Scenario: 强制重译渐进显示
- **WHEN** 用户对已有成功译文（包括自动读取的缓存译文）选择重新翻译
- **THEN** 请求必须强制跳过旧缓存，不再次读取缓存或以旧缓存结束任务；首段非空新预览到达后逐步显示新译文，空预览不清空旧内容，最终成功后更新成功结果；失败或取消恢复旧成功译文与既有缓存

#### Scenario: 清空按钮二次确认
- **WHEN** 用户第一次激活清空按钮
- **THEN** 只将按钮文案改为确认，不清理缓存；再次激活才清空，退出重入时确认状态重置

#### Scenario: 清空时有在途请求
- **WHEN** 用户清空缓存后旧请求完成
- **THEN** 结果可供本次查看，但不会回填已清空的缓存

### Requirement: 单请求渐进正文
首次翻译 MUST 使用当前整篇 Markdown 的单个流式请求，正文按服务返回顺序渐进显示，MUST NOT 引入分段并行或整篇 JSON 译文包装。重新翻译 MUST 同样渐进展示新正文；既有的加载、取消、旧成功结果回退与最多一次定向修复规则保持有效，MUST NOT 为思考参数策略增加翻译状态机分支。

#### Scenario: 首段到达
- **WHEN** 单请求收到第一段正文
- **THEN** 通过既有预览事件逐步显示译文，不等待全部正文完成，不按并发块重排页面

### Requirement: 流式预览容错
流式预览 MUST 容忍尚未完整输出、重复或乱序的 description 保护标记，不因标记位置触发 panic。最终输出 MUST 继续经过既有保真校验，符合既有条件时进入至多一次定向修复，不得将预览容错视作保真通过。

#### Scenario: 结束标记先于开始标记
- **WHEN** 流式内容中 description 结束标记位于开始标记之前
- **THEN** 预览不中断任务，最终校验拒绝损坏输出，既有定向修复仍可规划损坏片段

### Requirement: 不遮挡阅读的翻译进度
手动翻译开始后 MUST 在内容面板顶部立即显示不拦截交互的细意图进度条，等待、流式输出和定向修复期间保持反馈。未知完成比例 MUST NOT 显示为数值百分比。仅成功完成可收尾到终点并淡出；失败或取消 MUST 撤下，保留可阅读内容。进度 MUST 有可访问名称，完成反馈不得抢夺焦点；减少动态效果偏好下 MUST 使用静态反馈。

#### Scenario: 首段前仍可阅读
- **WHEN** 用户点击翻译且首段正文尚未返回
- **THEN** 顶部显示进度，正文保持原文可阅读、选择和滚动，不显示遮挡正文的加载动画

#### Scenario: 重译或终止
- **WHEN** 重译尚未完成，或翻译失败或被取消
- **THEN** 重译首段新正文前保留旧成功译文，之后渐进显示新正文；失败或取消恢复旧译文并撤下进度，不显示成功收尾，正文继续可读

#### Scenario: 缓存和减弱动画
- **WHEN** 初次打开只命中已有译文，或用户启用减少动态效果
- **THEN** 缓存命中不播放手动任务完成动画，减少动态效果时进度采用静态呈现

### Requirement: 翻译通知与上下文操作
技能详情翻译任务失败及翻译配置读写错误 MUST 仅通过 Toast 通知，不渲染正文条幅。任务失败通知 MUST 由共享会话发出，同一终止事件不得重复通知。任务提示 MUST 简短单句，可使用发起时已有技能名称前缀，不增加来源查询或路径、模型、任务编号等附加说明。翻译分体按钮右侧 MUST 在进行中显示中止、终止失败后显示重试，其余状态隐藏；自动修复仍属进行中。按钮 MUST 仅显示图标，以悬停提示及可访问名称表达动作。编辑、未保存或配置读取未决时重试 MUST 遵守原翻译可用性限制，中止不受编辑模式限制。

#### Scenario: 失败与重试
- **WHEN** 翻译任务终止失败并收到重复失败事件
- **THEN** 仅通知一次错误 Toast，保留可阅读内容，不插入条幅；工具栏显示重试，点击后变为中止

#### Scenario: 修复和结束
- **WHEN** 翻译进入自动修复，或最终成功或手动中止
- **THEN** 修复中只显示中止，不显示重试；成功或中止后隐藏上下文按钮，不将中止作为失败通知

#### Scenario: 配置失败与编辑模式
- **WHEN** 配置读取失败，或正在编辑原文且有在途翻译任务
- **THEN** 配置失败只通过 Toast 告知；编辑模式允许中止在途任务，但禁止对草稿直接重试

#### Scenario: 并行任务的精简反馈
- **WHEN** 用户切换页面后，多个后台翻译任务返回失败或修复提示
- **THEN** 每条提示使用对应任务发起时的上下文；有现成名称时可简短标识，没有时使用通用短提示，不套用当前页面名称

#### Scenario: 简短且可区分的错误原因
- **WHEN** 翻译任务因额度耗尽、请求受限、认证失败、超时或其他已知错误结束
- **THEN** 原有 Toast 显示对应的应用内本地化简短原因，额度耗尽不提示稍后重试；未知错误回退为通用翻译失败，不显示原始服务商消息、错误码、请求编号或重置时间，不新增条幅或详情面板

### Requirement: 流式说明及时展示

description 与正文 MUST 继续使用同一次模型请求。流式输出包含唯一、完整、有序的 description 起止标记及非空译文后，预览 MUST 将译文安全序列化回 frontmatter，无需等待正文生成结束；其余字段的语义值 MUST 保留。description 尚未完整或标记异常时 MUST 保留原头部。预览 MUST NOT 绕过最终保真校验或写入未完成缓存。

#### Scenario: 正文尚未完成
- **WHEN** description 标记和值已完整到达，正文仍在生成
- **THEN** 顶部 description 显示译文，正文继续流式更新，不发起额外模型请求

#### Scenario: 不完整或异常说明
- **WHEN** description 结束标记尚未到达、值为空或边界标记重复或逆序
- **THEN** 预览保留原 description，最终输出仍由既有保真校验决定是否可缓存
