# skill-content-translation Specification

## Purpose

定义用户在技能详情阅读当前 Markdown 文件时的手动翻译行为，覆盖语言与模型偏好、工具栏呈现、任务生命周期、内容保护、缓存及失败恢复，始终保持技能原始文件与编辑草稿独立。

## Requirements

### Requirement: 按当前文件手动翻译
本地技能详情 MUST 支持当前打开的 SKILL.md 及技能目录内其他 `.md` 文件，含只读、插件、外部导入和归档来源。MUST NOT 自动、递归、批量翻译或抓取外部链接；仓库远程预览与新建未保存技能不在本能力范围。未保存或正在保存的当前文件 MUST 提示先保存，不发送草稿或与当前显示不一致的磁盘内容。

#### Scenario: 多个参考文件
- **WHEN** 技能有大量 references Markdown，用户手动翻译其中一篇
- **THEN** 只读取与翻译该篇，不产生其他文件的请求

### Requirement: 工具栏翻译入口
翻译 MUST 使用紧跟查看/编辑/分屏右侧的单一下拉按钮，含 Languages 图标、翻译文字、下箭头；高度、圆角、字号与图标匹配现有工具栏，可用细分隔线。MUST 使用中性色，MUST NOT 放在 Skill 管理区或提供右键翻译。编辑/分屏时保留位置但禁用并提示切换到查看；非 Markdown 不显示。

#### Scenario: 只读技能
- **WHEN** 用户查看只读技能的 Markdown
- **THEN** 查看控件旁仍显示翻译入口，不依赖编辑权限

### Requirement: 状态与只读展示
下拉 MUST 提供翻译为当前目标语言、语言选择、翻译设置；有结果时提供原文/译文切换与重译，进行中提供取消。初次翻译流式显示，允许查看原文；重译期间保留旧成功译文，成功后替换。译文通过按钮选中态与 tooltip 标识，无常驻模型/AI 文字。编辑或分屏 MUST 使用原文，任何译文 MUST NOT 进入原文草稿或保存路径。重新进入文件默认原文，不自动发请求。

#### Scenario: 从译文进入编辑
- **WHEN** 用户在译文视图切到编辑
- **THEN** 编辑器仅显示原文，已有草稿保护继续生效

### Requirement: 目标语言偏好
翻译语言 MUST 独立于界面语言，支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语。没有已保存偏好时 MUST 用设备首选语言匹配，其次界面语言，最后英语；读取语言不请求敏感权限，不发送完整语言偏好列表。用户在菜单或设置中修改 MUST 持久化，后续系统/界面变化 MUST NOT 覆盖。

#### Scenario: 繁体设备语言
- **WHEN** 无翻译偏好且设备语言为 zh-TW
- **THEN** 默认繁体中文；用户修改后重新打开仍使用所选语言

### Requirement: 模型连接与翻译设置分离
模型供应商管理连接与凭据，翻译设置 MUST 仅引用供应商/模型并管理语言与清缓存。未选择模型 MUST 提供设置入口，MUST NOT 发请求；供应商/模型均须启用。配置入口 MUST 可从详情打开，关闭后保留当前文档；配置成功 MUST NOT 自动触发生成。界面 MUST 告知当前文档将发送给所选服务。

#### Scenario: 首次配置
- **WHEN** 用户无翻译模型并进入设置完成配置
- **THEN** 返回原文档，由用户再次触发翻译

### Requirement: 设置入口与弹窗导航
设置主页面 MUST 仅显示「模型设置」与「翻译选项」的独立入口卡片及状态摘要，不展开表单。下拉项 MUST 沿用应用自定义菜单与选中标记，标签与控件使用一致间距，MUST NOT 使用系统原生下拉外观。入口与技能详情的翻译设置 MUST 使用同一套带遮罩的详情弹窗。翻译页 MUST 只提供语言、模型选择与缓存操作，不显示前往模型设置的说明或按钮；模型服务通过独立入口管理。两个设置入口 MUST 使用不同的按钮图标与文字（模型管理与翻译设置）。供应商编辑在弹窗内切页，不叠加设置详情弹窗。重新打开翻译页 MUST 保留原语言与模型偏好并刷新可选模型，MUST NOT 自动选用新增模型或发起翻译。独立进入供应商管理 MUST NOT 要求配置翻译。

#### Scenario: 独立管理连接后重新打开翻译
- **WHEN** 用户关闭翻译选项，通过独立模型管理入口新增连接后再打开翻译选项
- **THEN** 翻译选项重新打开后，原语言与原选用模型不变，新可用模型出现在选项中，由用户决定是否选用

#### Scenario: 独立打开供应商设置
- **WHEN** 用户从设置主页面打开模型供应商
- **THEN** 只展示连接管理，关闭后焦点返回原入口，不展示翻译表单或改变翻译偏好

### Requirement: 取消与结果身份隔离
请求 MUST 在发起前拥有可取消的身份；显式取消、切换文件/技能、离页、源内容或目标变化 MUST 终止客户端任务并忽略迟到结果。取消 MUST NOT 报错或提交部分缓存。正常完成提交与取消 MUST 有唯一先后顺序，提交后取消不撤销成功缓存；不承诺供应商服务端停止生成或计费。

#### Scenario: 首块前离开
- **WHEN** 请求发出但尚无首块时用户切换文件
- **THEN** 取消仍有效，旧结果不影响新文件

### Requirement: 受保护内容保真
围栏代码块、行内代码、链接目标和 frontmatter 非 description 字段 MUST 通过确定性保护保持原文；description 可翻译。保护标记缺失、重复或被改写时 MUST 失败且不缓存。提示词 MUST 要求自然语言中的路径/命令、Markdown 结构与已为目标语言的内容保持原样，但不得将模型质量目标宣传为所有自然语言命令均可安全执行。

#### Scenario: 模型改坏标记
- **WHEN** 返回结果丢失保护标记
- **THEN** 显示保真失败，保留原文与已有成功结果，不写新缓存

### Requirement: 完成与失败判定
只有明确正常完成且非空、通过保护校验的输出 MUST 被当作成功。截断、拒绝、未知/缺失终止原因、异常断流 MUST 显示内联错误和手动重试，MUST NOT 缓存；无错误弹窗或自动付费重试。请求 MUST 有首响应、流空闲与总超时。源文上限 MUST 为 51,200 UTF-8 字节，超过时不请求；输出也须有界。

#### Scenario: 输出截断
- **WHEN** 服务正常结束连接但终止原因是 token 上限
- **THEN** 不显示完整成功，不覆盖旧成功缓存，提示调整模型输出上限后重试

### Requirement: 缓存与重新翻译
缓存 MUST 由有效协议、规范化 URL、模型、headers、输出参数、目标语言、源文及翻译策略版本决定，不含技能/文件 ID 或 API Key；同有效配置可共享。只在成功提交后原子写入应用缓存，MUST NOT 修改技能文件。重译 MUST 跳过旧缓存读取但保留旧条目至新结果成功。清空 MUST 不影响其他数据，清空前已在途任务 MUST NOT 将结果写回缓存。

#### Scenario: 重译失败
- **WHEN** 缓存已有成功译文，用户重译失败
- **THEN** 旧译文和旧缓存仍可用

#### Scenario: 清空时有在途请求
- **WHEN** 用户清空缓存后旧请求完成
- **THEN** 结果可供本次查看，但不会回填已清空的缓存
