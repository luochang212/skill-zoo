# llm-provider-config Specification

## Purpose

定义桌面应用可复用的模型供应商连接配置，包括协议、模板、可用模型、凭据与持久化边界，使内容翻译及后续功能能独立选择连接而无需重复保存凭据。

## Requirements

### Requirement: 三协议供应商与模板
供应商 MUST 使用 anthropic-messages、openai-chat-completions、openai-responses 之一，不提供高级选项或自定义请求头。供应商包含唯一的不可编辑 ID、非空名称、启用状态、Base URL、可选 API Key 及模型列表。新增 MUST 提供随应用内置的 OpenAI、DeepSeek、Volcengine 与自定义模板，连接选择/编辑/保存 MUST NOT 调用模型服务；只有模型编辑器可读取公开模型目录元数据。所有模板 MUST 只预填连接信息，不预设任何模型，模型由用户自行添加。自定义 MUST 作为第四张同尺寸网格卡片，使用轻微色彩和加号区分，不提供 Ollama 预置卡片或底部自定义横条。

#### Scenario: 自定义服务
- **WHEN** 用户选择自定义模板并填写协议、地址与模型
- **THEN** 可保存连接，调用时使用明确选择的协议，不根据模型名推断

#### Scenario: 火山引擎模板
- **WHEN** 用户选择 Volcengine
- **THEN** 预填 OpenAI Chat Completions 协议与 https://ark.cn-beijing.volces.com/api/v3/，模型列表保持为空

#### Scenario: 预置列表收敛
- **WHEN** 用户打开供应商选择面板
- **THEN** 只显示 OpenAI、DeepSeek、Volcengine、自定义四张卡片；已保存的其他供应商仍可管理和调用，不迁移或删除其配置

### Requirement: 首次选择服务与后续列表管理
首次无服务时和点击添加服务时 MUST 使用同一个无侧边栏的供应商选择面板。选择任意预置或自定义供应商后 MUST 进入带侧边栏的配置页，窄窗口上下排列；新服务草稿在导航中标记未保存，保存后选中新服务。详情 MUST 分离连接信息与模型列表，参数使用独立弹窗。新建与已有服务 MUST 共用原侧边栏配置页，名称点击后编辑，三个点提供删除，均按自动保存规则持久化；首次有效编辑完成后创建服务，打开表单或选择模板不得写入，切换或关闭前 MUST 等待在途保存，仍有未保存修改时确认放弃，MUST NOT 自动改绑翻译模型或启动翻译。

#### Scenario: 模型管理的连接与草稿布局
- **WHEN** 用户打开已有服务的管理页
- **THEN** 导航突出名称与启用模型数，添加入口固定于导航底部，详情不提供底部取消/保存按钮，显示轻量保存状态；名称在标题处编辑，服务开关在标题右侧三个点左边，新建服务同样使用标题改名、标题右侧开关与三个点删除
- **AND** 模型列表支持添加/移除，模型行提供独立编辑按钮；新模型默认可用，已有禁用模型保留状态且标记禁用，不提供模型开关
- **AND** 新建与已有服务均不提供保存或取消按钮；通过添加入口回到无侧边栏的模板选择面板，存在未保存修改时先确认放弃

#### Scenario: 密钥普通编辑与显式保存
- **WHEN** 用户编辑已有服务的密钥
- **THEN** 专用 IPC 读取真实值并以密码框默认隐藏，眼睛切换显隐，长度跟随真实值，不使用固定假掩码；新建直接输入
- **AND** 输入过程中及全选删除时只修改草稿，失焦后自动保存才生效；输入框内仅提供显隐按钮，不提供清除图标；未改动保留原密钥
- **AND** 读取期间或读取失败不得编辑密钥或提交，避免误保存为空

#### Scenario: 首次连接 Anthropic
- **WHEN** 用户无服务并通过自定义配置 Anthropic 兼容连接
- **THEN** 同一侧边栏弹窗的右侧展示其预填表单，不显示保存/取消按钮；打开时不保存或调用模型，首次有效编辑完成后自动保存

#### Scenario: 已有服务继续添加
- **WHEN** 用户已有服务并点击导航底部的添加服务
- **THEN** 进入无侧边栏的模板选择面板，选择供应商后恢复侧边栏，保存后选中新服务并显示其详情，原翻译偏好保持不变

#### Scenario: 切换管理对象保留用户选择权
- **WHEN** 用户修改连接信息后切换另一服务商或添加服务
- **THEN** 先完成当前输入的保存并等待在途请求；成功后直接导航，失败或校验未通过则确认放弃，继续编辑保留当前草稿，翻译偏好均不改变

#### Scenario: 新服务草稿切换
- **WHEN** 用户编辑尚未保存的新服务后点击已有服务、添加入口、返回翻译设置或关闭弹窗
- **THEN** 保留侧边栏并先确认放弃；继续编辑保留草稿，确认放弃后才执行目标操作，未保存草稿不落盘

#### Scenario: 相同供应商选择面板
- **WHEN** 用户首次无服务进入，或从已有服务导航点击添加服务
- **THEN** 展示相同的预置与自定义供应商卡片，不展示服务导航或添加服务按钮；已有服务时可返回之前的管理对象

#### Scenario: 选择自定义供应商
- **WHEN** 用户从供应商选择面板选择自定义
- **THEN** 配置页恢复侧边栏并显示未保存的自定义草稿，保存前不创建持久化服务

#### Scenario: 首次自动保存中的后续编辑
- **WHEN** 新服务首次自动保存尚未返回时用户继续修改
- **THEN** 保留新输入并按顺序保存，后续写入使用首次返回的同一供应商 ID，不重复创建服务，不重置编辑草稿

#### Scenario: 新服务草稿删除
- **WHEN** 用户从三个点确认删除尚未持久化的供应商
- **THEN** 放弃本地草稿并回到供应商选择；在途自动保存先完成，如已持久化则删除对应供应商

### Requirement: 地址与模型校验
Base URL MUST 是无用户信息、无查询/片段的 HTTP(S) API 根地址，保存时规范化为尾斜杠；支持 localhost HTTP。模型 ID MUST 非空且同供应商内唯一，输出上限若设置 MUST 为正整数。模型列表允许为空，模型条目保留启用状态以兼容已有配置，当前界面不提供独立启用开关；本次不提供 temperature、推理档位或排序配置。

#### Scenario: 无尾斜杠地址
- **WHEN** 用户保存 https://example.test/v1
- **THEN** 规范化为 https://example.test/v1/，请求保留 v1 路径

#### Scenario: 非法条目
- **WHEN** 存在非法地址或重复模型
- **THEN** 保存失败，显示可识别字段，原配置不变

### Requirement: 凭据通过专用接口查看
普通供应商列表 MUST 只返回 Key 是否存在；编辑页 MUST 通过专用 Rust IPC 读取实际 Key，默认隐藏并允许用户显式显示。Key MUST NOT 出现在日志/错误中。编辑凭据 MUST 区分未变、替换、清除；清空草稿并保存 MUST 清除原 Key，空 Key 允许用于无认证本地服务。打开表单、查看 Key 或输入过程中 MUST NOT 自动保存或发起连接测试；已有服务的密钥编辑完成后按自动保存规则持久化。实际认证失败由调用报告，MUST NOT 在保存时验证联网。

#### Scenario: 修改名称
- **WHEN** 用户只修改名称而不替换凭据
- **THEN** 原 Key 保持不变，普通列表及保存摘要没有任何 secret 值

### Requirement: 独立且原子持久化
供应商 MUST 使用带 schemaVersion 的独立配置，原子落盘成功后才切换可用配置。Unix 凭据文件及临时文件 MUST 为 0600；Windows 沿用用户应用目录的继承 ACL，不承诺 Unix 权限语义。当前版本为 1；未知/未来版本 MUST 保留原文件并拒写，不假设能展示未知条目。损坏配置 MUST 报错并拒写，用户显式恢复后先备份原文件，再创建空配置。

#### Scenario: 损坏配置恢复
- **WHEN** 用户确认恢复损坏配置
- **THEN** 原字节保留在唯一备份文件，新的空配置可保存且重启可读

#### Scenario: 未来版本
- **WHEN** 配置 schemaVersion 高于支持版本
- **THEN** 显示版本不支持，不覆盖或自动恢复该文件

### Requirement: 禁用删除与可用性
删除 MUST 经确认；禁用供应商或模型 MUST 阻止其被新的翻译请求使用。已保存的翻译目标失效 MUST 显示不可用，MUST NOT 静默切换到其他供应商。删除供应商可保留派生缓存，同有效请求配置允许共享缓存。

#### Scenario: 当前目标删除
- **WHEN** 当前翻译供应商被删除
- **THEN** 翻译提示重新选择，下一次请求不会自动发给另一家服务

### Requirement: 模型参数编辑
模型行 MUST 提供编辑图标，添加/编辑模型使用同一参数弹窗，支持模型 ID、可选上下文窗口与最大输出 token。取消不修改草稿；确认更新当前服务草稿，新建与已有服务均随即按自动保存规则持久化；模型 ID MUST 非空且同服务唯一，数值 MUST 为正整数，均设置时输出上限 MUST NOT 超过上下文窗口。上下文窗口作为元数据保存，不声称可精确计算 token；最大输出继续用于模型请求。

#### Scenario: 编辑事务取消
- **WHEN** 用户编辑参数或接收自动回填后取消
- **THEN** 服务草稿、已保存配置与翻译偏好不变

### Requirement: 公开模型目录识别
智能识别 MUST 通过 Rust IPC 读取 Models.dev 的固定匿名 JSON 目录，MUST NOT 上传 API Key、请求头或文档。目录按内存 TTL 缓存，限定请求时限与响应体大小。匹配 MUST 优先服务地址及完整模型 ID，再尝试可靠识别的原厂条目（完整 ID 优先于精确末段 ID）；原厂候选有效时采用。其余候选按完整 ID、精确末段 ID 分级，以有效「上下文窗口、最大输出」组合的众数选择；各优先级中并列众数（含各组合均只出现一次）MUST 按候选固定遍历顺序取第一个已有配置，无有效结果不回填，当前服务条目无效时不绕过。MUST NOT 使用子串或型号近似匹配，不改变请求地址或模型 ID；目录未收录或网络失败 MUST 保留手动编辑与确认。公开目录只提供参考，不验证模型在当前账号可用性。

#### Scenario: 自定义模型未识别
- **WHEN** 模型 ID 无可用匹配、候选均无有效推荐，或公开目录不可达
- **THEN** 静默保留手动填写与确认，不显示失败/未匹配提示或 toast，不改用其他模型

#### Scenario: 中转与命名空间模型
- **WHEN** 中转或 Coding Plan 地址未命中目录，但完整模型 ID 或去除命名空间后的精确 ID 有一致的推荐参数
- **THEN** 回填参数，实际地址与模型 ID 保持用户输入

#### Scenario: 优先级与候选冲突
- **WHEN** 当前服务有精确匹配，或兜底候选存在并列众数
- **THEN** 优先采用当前服务参数；并列时在当前匹配层取固定顺序的第一个有效配置，不从较低优先级选择其他值

#### Scenario: 原厂优先于中转差异
- **WHEN** 中转地址上的 qwen3.8-flash 候选参数不同，但阿里云原厂条目有一致有效的参数
- **THEN** 采用原厂参数，不因其他中转条目不同而放弃匹配

#### Scenario: 无可靠原厂时取众数并确定性处理并列
- **WHEN** 无可靠原厂推荐，候选限制组合出现次数分别为 2、1、1 或 2、2
- **THEN** 前者采用出现两次的组合，后者采用并列组合中固定顺序的第一个配置；不得分别对两个参数取众数拼出不存在的组合

### Requirement: 推荐值与编辑身份隔离
弹窗打开或 ID 改变后，仅当上下文窗口和最大输出 token 均为空时 MUST 防抖查询；任一字段非空 MUST NOT 发起查询。两个字段清空后可重新自动查询；请求过程中任一字段被填写，旧结果 MUST NOT 再回填。自动结果只填写未保存且未手动修改的字段。已有数值 MUST 保留，不提供使用推荐配置按钮或操作说明。自动匹配成功 MUST 复用现有 toast 提示，未匹配或失败 MUST 静默处理，不显示常驻匹配状态。关闭、服务地址变化、ID 往返切换后，旧成功/失败结果 MUST NOT 污染新草稿或反馈；请求过程中新的手动输入 MUST 优先。自动回填 MUST NOT 保存配置、切换翻译偏好或发起翻译。

#### Scenario: 手动输入优先于迟到推荐
- **WHEN** 用户输入新模型 ID 后在目录请求完成前手改最大输出
- **THEN** 忽略返回结果，不再自动填写任一字段，保留用户输入

#### Scenario: 模型 ID 首尾空白变化
- **WHEN** 用户只增删模型 ID 的首尾空白，去除首尾空白后的 ID 未变
- **THEN** 保留已匹配参数，不重新发起或使当前匹配失效

#### Scenario: 输入法组合输入
- **WHEN** 用户在模型 ID 框进行尚未完成的输入法组合输入
- **THEN** 不发起自动查询，组合输入结束后对最终 ID 重新开始防抖计时，组合输入前的迟到结果不得回填

### Requirement: 不支持自定义请求头
连接配置 MUST NOT 暴露高级选项、自定义请求头读写或发送能力。请求头只由协议、API Key 和请求格式生成；旧配置中的 headers 字段 MUST 被忽略，不发送到模型服务。

#### Scenario: 旧配置包含请求头
- **WHEN** 读取带有旧 headers 字段的配置并调用模型
- **THEN** 仍可读取连接，但不使用该字段，修改其他配置不恢复自定义头能力

### Requirement: 设置内容自适应布局
模型设置弹窗 MUST 按当前内容决定高度，仅限制最大高度，长内容滚动，新建与已有服务的保存状态和失败重试保持可见，不提供取消/保存按钮。服务商导航 MUST NOT 因列表较长将短表单撑高，短内容末尾与底栏之间只留标准内边距。宽度允许并排时，接口类型与服务地址 MUST 按 2:3 分配可用宽度，窄窗口上下排列。模型标题旁的添加按钮与列表 MUST 位于模型区及弹窗边界内，空列表与窄窗口均不得横向越界。

#### Scenario: 无预设模型的短表单
- **WHEN** 用户选择任一推荐服务商或自定义服务，尚未添加模型
- **THEN** 模型列表为空，弹窗随内容收高，模型区域末尾保持标准内边距，不保留固定高度造成的大块空白

### Requirement: 显式模型添加与输入法安全
模型列表 MUST 只通过标题旁的添加按钮打开空模型参数弹窗，不提供列表外的模型 ID 输入框或 Enter 跳转编辑快捷键。新增弹窗标题为添加模型，ID 初始为空；确认后才加入服务草稿，已有模型只通过行内编辑按钮编辑。

参数弹窗 MUST NOT 通过输入框回车隐式确认参数、保存服务、关闭弹窗或触发翻译；确认参数 MUST 仅由显式激活「确定」按钮触发。中文输入法的回车 MUST 保持原生选字行为。普通回车与输入法候选确认回车均 MUST 保持弹窗打开，不取消尚未完成的自动目录匹配。

#### Scenario: 显式添加模型
- **WHEN** 用户激活模型列表标题旁的添加按钮
- **THEN** 打开 ID 为空的添加模型弹窗，填写并确认后才加入服务草稿

#### Scenario: 回车不提前确认
- **WHEN** 模型 ID 或参数输入框内按回车，自动目录匹配尚未返回
- **THEN** 弹窗保持打开，不确认参数或保存服务，匹配结果仍可按原规则回填

#### Scenario: 拼音候选确认
- **WHEN** 用户在添加或编辑弹窗的模型 ID 中使用拼音并按 Enter 确认候选
- **THEN** 只完成输入，弹窗保持打开，不确认参数或提交服务

### Requirement: 显式最小推理连接测试
每个模型 MUST 提供显式测试连接操作，使用当前未保存的协议、地址、模型和凭据。测试 MUST 发出一次固定短提示的非流式推理请求，不请求模型列表、不自动重试。Chat Completions 与 Messages 输出预算 MUST 为 1 token，Responses MUST 使用其最低允许的 16 tokens。测试 MUST 在 15 秒内结束；预算耗尽或正文为空但响应结构及结束状态有效时 MUST 判为可用，不沿用翻译的非空完整正文要求。

#### Scenario: 空正文的最小推理
- **WHEN** 服务返回有效推理结构且因输出预算耗尽结束，正文为空
- **THEN** 测试成功并显示耗时，不显示翻译截断错误

#### Scenario: 无效或失败响应
- **WHEN** 请求超时、鉴权失败、限流，或服务返回非推理响应
- **THEN** 测试失败并显示安全的原因，不将 HTTP 200 单独视为成功

### Requirement: 测试隔离与凭据保护
测试调用本身 MUST 不保存连接、不改变偏好或翻译缓存、不发送技能内容。未替换的密钥 MUST 只在后端读取；替换或清除使用当前草稿。反馈 MUST 不含密钥、上游响应体或原始网络错误。测试期间 MUST 防止重复提交，配置改变、切换服务或关闭后旧结果 MUST NOT 产生误导性成功反馈。未主动测试时 MUST NOT 发起推理请求。

#### Scenario: 未保存的连接修改
- **WHEN** 用户修改地址或密钥后测试某个模型
- **THEN** 使用草稿测试，测试调用本身不写配置、不改变偏好及缓存；已有服务因输入失焦触发的自动保存独立处理

#### Scenario: 测试中改变草稿
- **WHEN** 测试尚未返回时修改配置或离开当前服务
- **THEN** 旧结果不显示为当前配置的成功或失败

### Requirement: 协议请求路径与认证
连接测试与翻译 MUST 复用相同协议路由和认证。Anthropic Messages MUST 在 API 根路径末尾尚无 `/v1` 时补齐该前缀，再调用 `messages`，已有 `/v1` MUST NOT 重复添加；非空 Key MUST 同时用于 `x-api-key` 和 Bearer Authorization，保留 `anthropic-version: 2023-06-01`。Chat Completions 与 Responses MUST 保留用户填写的 API 根路径，分别调用 `chat/completions` 与 `responses`，非空 Key 使用 Bearer Authorization。空 Key MUST 不发送认证头，不读取环境凭据；MUST NOT 改写持久化地址或自动重试。

#### Scenario: Anthropic 网关根地址
- **WHEN** 用户使用根路径为 `/anthropic/` 的 Anthropic 兼容服务
- **THEN** 连接测试和翻译请求 `/anthropic/v1/messages`，非空 Key 同时出现在两种认证头中

#### Scenario: 已带版本与自定义 OpenAI 根路径
- **WHEN** Anthropic 地址已以 `/v1/` 结束，或 OpenAI 协议配置了自定义根路径
- **THEN** Anthropic 只添加 `messages`，OpenAI 协议保留根路径并添加对应接口后缀，不擅自添加 `/v1`

#### Scenario: 匿名服务
- **WHEN** 任一协议使用空 Key
- **THEN** 测试与翻译均不发送 `x-api-key` 或 Authorization，不回退到环境中的凭据

### Requirement: 模型流错误安全分类
模型服务在 HTTP 200 流中返回显式错误，或因协议数据无法解析而失败时 MUST 报告 `providerResponse`，而非网络连接失败；HTTP 401/403、429 与超时 MUST 继续使用各自安全分类。错误反馈 MUST NOT 包含上游响应、模型输入或凭据，MUST NOT 自动重试或将部分输出当作成功。

#### Scenario: 服务端流错误
- **WHEN** 三种协议之一在 HTTP 200 流中返回错误事件
- **THEN** 翻译失败并报告安全的服务响应错误，不返回部分译文或泄漏服务端错误正文

#### Scenario: 非法流数据
- **WHEN** Chat Completions 或 Messages 返回无法解析的正文事件
- **THEN** 报告服务响应错误，不误导用户排查网络

### Requirement: 已有服务自动保存
已有服务的名称确认、地址与密钥有效失焦 MUST 自动保存；协议、启用状态和模型增删改确认 MUST 立即保存。输入中间态 MUST NOT 写入；无效或失败时 MUST 保留草稿和安全错误，支持显式重试。写入 MUST 按编辑顺序串行，旧响应 MUST NOT 覆盖新输入。界面 MUST 显示保存中和保存失败，不显示常驻的未保存修改提示，正常保存完成后 MUST 不显示常驻已保存提示，不自动切换翻译偏好或调用模型。首次添加服务按同一自动保存规则持久化；模型参数弹窗 MUST 保留显式确认。

#### Scenario: 连续编辑期间保存返回
- **WHEN** 一次保存尚未返回时用户完成下一次编辑
- **THEN** 下一次写入等待前次结束，表单保留最新输入，只有最新草稿保存成功才清除内部未保存状态，不显示常驻已保存提示

#### Scenario: 保存失败与离页
- **WHEN** 自动保存失败或地址无效，用户切换服务、返回或关闭管理页
- **THEN** 原输入保持可编辑且错误可识别；离页需确认放弃，继续编辑可重试，已保存配置保持最后成功值

#### Scenario: 安静编辑但保留离开保护
- **WHEN** 用户正在输入或保留无效的地址草稿
- **THEN** 右下角不显示未保存修改提示；切换或关闭时仍按草稿保护规则处理，不丢弃输入

### Requirement: 模型思考偏好
模型 MUST 保存默认关闭的深度思考偏好；旧配置缺字段 MUST 按关闭读取。编辑与添加模型弹窗 MUST 将深度思考开关放在第一个选项，确认才提交，取消不改变草稿。可操作性 MUST 由后端结合服务地址、协议和模型确定，前端仅显示可操作或不可操作的开关，MUST NOT 显示能力分类、查询状态、失败提示或状态 toast。配置身份改变后旧查询 MUST NOT 影响新模型。

后端 MUST 只对已确认支持的服务与模型发送相应思考参数；未知或不支持切换的模型 MUST NOT 发送未经确认的参数，MUST NOT 自动协商或重试。最小连接测试 MUST 保持既有预算并在支持时关闭思考。偏好改变 MUST 隔离翻译缓存。

#### Scenario: 旧配置与取消
- **WHEN** 旧模型缺少思考偏好，用户打开编辑后操作开关并取消
- **THEN** 初始关闭，取消不改变保存配置或服务草稿

#### Scenario: 未知能力与迟到查询
- **WHEN** 模型未知、不可切换或能力查询尚未完成，或 ID 已变化
- **THEN** 开关不可操作且无额外状态文字，旧结果不能启用新 ID 的开关

#### Scenario: 支持的模型
- **WHEN** 对确认支持的服务模型发起翻译
- **THEN** 后端按已保存的默认关闭或显式开启偏好生成对应参数，无隐式失败重试
